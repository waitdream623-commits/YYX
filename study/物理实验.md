# 物理实验

## RC、RL 实验：示波器两通道为什么要共地

适用条件：普通共地示波器配合单端探头。隔离输入示波器、差分探头和独立电池供电万用表须按各自接线要求判断，不能一概而论。

- 普通示波器 CH1、CH2 的黑色地夹在仪器内部相通，台式机型通常还连接保护地；常见台式信号发生器的输出地也可能经保护地与其相通。
- 各通道测量的是探头尖端相对于地夹的电压：U_CH = V_尖端 - V_地夹。
- 两个地夹应接在电路同一个公共节点，不必夹在完全相同的物理位置；同一根理想导线上不同位置属于同一节点。高频测量还须考虑地线长度和回路影响。
- 若把两地夹分别接在不同节点 A、B，就相当于通过示波器的地线用低阻导线连接 A、B。若 A、B 之间有元件，该元件可能被旁路、短路，改变原电路，导致幅值、相位、截止频率测量失真；严重时造成过流并损坏元件或仪器。

例：A — R — B — C — O。CH1 地夹接 O，若 CH2 地夹接 B，则 B 与 O 被地线连接，电容 C 被短路。正确的共地接法是两地夹均接 O，探头尖端分别接 A、B，此时 CH1 测总电压，CH2 测电容电压。若要测 R 两端电压，可在仪器额定范围内，用 CH1 - CH2 得到 V_A - V_B，或使用合适的差分探头。

测量电阻电压时也可依实验图重新安排串联元件，使电阻一端位于公共地；还需同时核对信号源输出地。不要仅为更换被测元件而把某一路地夹移到另一节点，也不要断开示波器保护地。
