截图中的提交：`01:01:09` TLE（test 5，`397891649`）→ `01:17:59` WA（test 2，`397892155`）→ `01:19:31` TLE（test 5，`397892206`）。

赛时写了区间递归和递推，枚举选哪个位置，复杂度过高。复盘时想到枚举分界点，取左侧的正数和右侧负数的绝对值。

$+ + + + - + - + - - -,左正数，右负，可以直接相加，变为-+-+,此时需要枚举如果选左-结果就为$

此时有多种情况，我门肯定想转换会左正右负情况，如果要选负数必然从最右边开始选变为$- +$，依旧不满足，选择正或者负，最终结果为该点，前缀正和加上后缀负和，我们必然不会选择一开始就最先选择第一个负数，此时会损失右边负数

如果负数在左、正数在右，它们不能同时拿到。先取左边的负数会删掉右边的正数，先取右边的正数会删掉左边的负数。因此，任意选法中，拿到的正数都在拿到的负数左边，可以在两者之间切一刀。

固定一刀，左侧的正数从左往右取，右侧的负数从右往左取，两组都能拿全。比如 `[-3, 5, -7, 4]` 在 `5` 和 `-7` 之间切，先取 `5` 再取 `-7`，得 `12`。一开始就取 `-3` 会同时丢掉 `5` 和 `-7`。

设 `S(k)` 是切在前 `k` 个元素之后的得分。`S(0)` 等于所有负数的绝对值之和。分界向右跨过正数时加上它，跨过负数时减去它的绝对值，两种情况都是 `S(k) = S(k - 1) + a[k]`。所以答案是 **负数绝对值之和 + 最大前缀和（含空前缀）**。一次扫描，时间 `O(n)`，额外空间 `O(1)`，用 `long long` 求和。

> [!IMPORTANT]
>
> 枚举分界点，为负数，右边最大化可以从右往左选负数，不可能选正此时会把左边消掉

看了题解：

设当前重量为 `x`，最高置位是 `b`。最高位低于 `b` 的史莱姆一定能吃，异或后第 `b` 位仍为 `1`，所以可以一次吃完一整段。遇到最高位至少为 `b` 的第一只，再用**吃完这一段后更新的 `x`** 比较。如果 `x < w[j]` 就停，否则吃掉它。能吃时两者最高位必然相同，异或会清掉第 `b` 位。`x = w[j]` 也能吃，吃完变成 `0`，直接结束。

用 1 下标。`last[i][b]` 是 `[1,i]` 里最靠右、最高位至少为 `b` 的位置，不存在记 `0`。设 `i` 是下一个要尝试吃的位置，取 `j = last[i][b]`，用 `x ^= pre[i] ^ pre[j]` 批量吃掉 `[j+1,i]`，其中 `pre` 是前缀异或。若 `j = 0`，已经吃完。若能继续吃 `w[j]`，异或它并令 `i = j - 1`。每次继续时最高位至少下降一位，预处理 `O(30n)`，单次询问 `O(30)`。

## E. Mycraft Sand Sort

### 单调栈找同色候选

要找 `i < j`，满足 `c[i] == c[j]`，且中间每个高度都小于 `min(p[i], p[j])`。假设 `i` 是较矮的一端，`j` 必须是 `i` 右侧第一个比它高的位置。再往右找，这个更高的位置就会夹在中间。左侧同理。比如当前高度为 `3`，往右看到 `1, 4, 6`，只检查 `4` 的颜色，不能跨过它去配 `6`。

下面扫一趟右侧最近更高的位置。把遍历方向反过来，再扫一趟左侧。`p` 是排列，每对只会由较矮的一端找到一次，两趟合计 `O(n)`。

```cpp
vector<int> st;
for (int i = n - 1; i >= 0; --i) {
    while (!st.empty() && p[st.back()] < p[i])
        st.pop_back();

    if (!st.empty() && c[i] == c[st.back()]) {
        int j = st.back();
        // (i, j) 是一对同色候选。
    }
    st.push_back(i);
}
```

### 整题计数

重力只会让同一列的沙块下落，保留它们从上到下的顺序。第 `h` 列因此是所有 `p[i] >= h` 的颜色序列。把第 `h` 列变成第 `h+1` 列，就是删掉高度为 `h` 的位置。

在当前颜色序列里，删去位置 `u` 和删去位置 `v` 得到相同结果，当且仅当两者之间（含两端）全是同一种颜色。因为若 `u < v`，两种删除结果要在这一段逐位相等，就要求从 `u` 到 `v` 每一对相邻颜色都相同。因此，每一步可以从实际被删位置所在的**连续同色段**任选一项。每次选择都得到题目要求的下一列，整条删除顺序唯一确定各位置的高度，所以把每一步的可选数乘起来。

用双向链表记录存活位置的前驱和后继，用并查集记录当前的同色段及其存活人数。初始化时合并相邻同色位置。随后按高度 `h = 1..n` 找到原排列中高度为 `h` 的位置，先把它所在集合的存活人数乘进答案，再减一并从链表删掉该位置。如果删掉后新相邻的两个位置同色，就合并它们。最后对 `998244353` 取模，乘法中途也取模。时间 `O(n α(n))`，空间 `O(n)`。
