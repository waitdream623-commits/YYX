## A · Composite Permutation

[题目](https://codeforces.com/contest/2285/problem/A) · [本地代码](../../AcWaitd/Contest/Codeforces%20Round%201135%20(Div.%202)/A_Composite_Permutation.cpp)

要求构造排列，使每个位置的 i × p[i] 都是合数。

先考虑恒等排列。i ≥ 2 时 i² 都是合数，只有位置 1 不满足要求。将数值 1 与 4 交换：位置 1 和位置 4 的乘积都为 4，其余仍为 i²。因此 n ≥ 4 时输出 `4 2 3 1 5 6 ... n`；n ≤ 3 时没有合数可以放在位置 1，输出 -1。

知识点：先构造大部分位置成立的方案，再修补少量特殊位置。时间 O(n)。

## B · Diverse String

[题目](https://codeforces.com/contest/2285/problem/B) · [本地代码](../../AcWaitd/Contest/Codeforces%20Round%201135%20(Div.%202)/B_Diverse_String.cpp)

### 先分清两个阶段

1. 先翻转至多 k 个字符，0 变 1、1 变 0，得到字符串 t。
2. 从同一个 t 出发，至多一次将一个连续区间全部赋成 0 或全部赋成 1，统计不同结果的数量。区间长度不受 k 限制，每个结果都独立从 t 产生，不能把这些操作连续叠加。

例如 s = `000`、k = 0，第一阶段不能修改；第二阶段仍能得到 `000、100、010、001、110、011、111`，多样性为 7。

### 固定字符串，怎样避免重复计数

例如 t = `10101`，把三个 1 按出现顺序编号为 ①②③。将区间赋为 0，可以改掉的 1 为：

| 被改掉的 1 | 结果 |
| --- | --- |
| ① | 00101 |
| ② | 10001 |
| ③ | 10100 |
| ①② | 00001 |
| ②③ | 10000 |
| ①②③ | 00000 |

不能只改①③而保留②，因为区间连续。这里说的“连续的一段 1”是指在所有 1 的出现顺序中连续，中间允许夹着 0。

关键是：不同操作区间可能产生同一个结果，但只要确定第一个、最后一个被改掉的 1，结果就唯一确定。区间额外包含两侧的 0，不改变结果。

设有 o 个 1，选端点允许重合，产生的新结果数为：

$$
o+\binom{o}{2}=1+2+\cdots+o=\frac{o(o+1)}2.
$$

同理，有 z 个 0 时，将区间赋为 1 能产生 z(z+1)/2 种新结果。前一类减少 1，后一类增加 1，两类不会重复。再单独计入原字符串：

$$
D(z,o)=1+\frac{z(z+1)}2+\frac{o(o+1)}2.
$$

所以多样性只与字符数量有关，与排列顺序无关。`10101` 的多样性是 6 + 3 + 1 = 10。

### 再决定如何翻转

设 z ≤ o，将一个 0 翻成 1，多样性增加：

$$
D(z-1,o+1)-D(z,o)=o-z+1>0.
$$

固定总长度时，两种数量越不均衡，多样性越大。因此朝原本数量更多的字符翻转即可；数量相等时任选方向。翻完少数字符后可以提前停止，因为是“至多 k 次”。

例如 `10101`、k = 1：不改是 10；把 1 改成 0 仍是 10；把 0 改成 1 后有四个 1、一个 0，多样性变成 10 + 1 + 1 = 12。

令最终少数字符数量 m = max(0, min(z,o) - k)，多数数量为 n-m：

$$
\boxed{\text{ans}=1+\frac{m(m+1)}2+\frac{(n-m)(n-m+1)}2}
$$

```cpp
void solve() {
    int n, k;
    string s;
    cin >> n >> k >> s;
    long long z = count(s.begin(), s.end(), '0');
    long long o = n - z;
    long long m = max(0LL, min(z, o) - k);
    long long other = n - m;
    cout << 1 + m * (m + 1) / 2
              + other * (other + 1) / 2 << '\n';
}
```

时间 O(n)，额外空间 O(1)，不计输入字符串。乘法必须使用 long long。

知识点：统计不同结果时，寻找唯一描述结果的对象；本题用真正变化的首尾位置去重。先求固定状态的计数公式，再优化状态。

## C · Max Substitution

[题目](https://codeforces.com/contest/2285/problem/C) · [本地代码](../../AcWaitd/Contest/Codeforces%20Round%201135%20(Div.%202)/C_Max_Substitution.cpp)

每次只能把当前唯一最大值改成更小的正整数，统计所有可达数组，对 1000000007 取模。若最大值不唯一，则不能继续操作。

### 降序排列后，修改位置形成前缀

按原始值降序记为 a[1] ≥ ... ≥ a[n]。排序用于分析，原始位置仍被视为不同位置。

要修改原本较小的元素，必须先降低所有原本更大的元素。因此，任何结果中，真正发生变化的位置必然构成这个降序序列的一个前缀。

若恰好修改前 i 个位置，那么第 i 个元素首次被修改前，前 i-1 个位置都必须已经严格小于 a[i]，否则它不是唯一最大值。数值只会减小，所以最终这 i 个位置的值都在 [1, a[i]-1] 中。

反过来，若 a[1] > ... > a[i]，可以按此原始顺序逐个修改，每个位置直接赋成任意目标值 [1, a[i]-1]。此前已修改的值都更小，后面原始值也更小（i < n 时还要求 a[i] > a[i+1]），因此操作合法。共有 (a[i]-1)^i 种结果。

### 为什么遇到相邻相等就停止

若第一次相等出现在 a[j] = a[j+1]，在更大的元素降下来以后，这两个相等的最大值互相阻挡，无法修改其中任何一个，也无法继续修改更小值。

因此只统计 i < j 的前缀；若没有相等，则可以统计到 n。不同前缀长度对应“真正修改的位置数”不同，不会重复；额外加 1 表示原数组。

```cpp
sort(a.begin(), a.end(), greater<int>());
long long ans = 1;
for (int i = 0; i < n; ++i) {
    if (i + 1 < n && a[i] == a[i + 1]) break;
    ans = (ans + qpow(a[i] - 1, i + 1)) % MOD;
}
```

例如原数组 `[5,3]`：不修改有 1 种；只改原来的 5，可选 1..4，共 4 种；两个都改，每个可选 1..2，共 4 种，总共 9 种。`[2,2,1]` 一开始最大值不唯一，只能保留原数组，答案 1。

知识点：先确定哪些位置能被修改，再按修改前缀长度分类计数；同时证明每个目标状态都能通过合法操作到达。排序与快速幂合计 O(n log n)，快速幂用 long long 乘法并及时取模。
