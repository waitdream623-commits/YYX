# 牛客挑战赛 94

## A · 区间并交操作

[题目链接](https://ac.nowcoder.com/acm/contest/143407/A)

原思路按左端点排序，用一个区间维护当前并集，同时把产生的交集计入答案。算式能正确更新一次操作的权值，但交集之后仍能参与操作，只跟踪最外层并集会漏掉这些机会。

例如 [1,4]、[2,5]、[3,6]。按原思路得到 [1,6]、[2,4]、[3,5]，权值和为 54。再对后两个区间做一次操作，得到 [1,6]、[2,5]、[3,4]，权值和为 56。

把左右端点作为事件排序，遇到左端点就入栈，遇到右端点就弹出栈顶与它配对。**同一坐标先处理左端点**，这样也能配出长度为 1 的闭区间。

证明时按右端点从小到大固定配对。设当前右端点 $r$ 在某个方案里对应 $l$，栈顶是 $l'$，且 $l'$ 当前配的是 $r'$。如果需要调整，那么 $l\le l'\le r\le r'$。对 $[l,r]$ 和 $[l',r']$ 做一次并交操作，得到 $[l,r']$ 和 $[l',r]$，正好让 $r$ 配到栈顶。权值增加 $2(l'-l)(r'-r)\ge 0$。已经固定的配对无需改动，因此从任意可达方案出发，都能通过这些操作得到同样的栈配对，权值也不会下降。

~~~cpp
void wait() {
    int n;
    cin >> n;

    vector<pair<long long, int>> events;
    events.reserve(2 * n);
    for (int i = 0; i < n; ++i) {
        long long l, r;
        cin >> l >> r;
        events.emplace_back(l, 0);
        events.emplace_back(r, 1);
    }
    sort(events.begin(), events.end());

    vector<long long> starts;
    long long ans = 0;
    for (auto [x, type] : events) {
        if (type == 0) {
            starts.push_back(x);
        } else {
            long long len = x - starts.back() + 1;
            starts.pop_back();
            ans = (ans + len * len) % MOD;
        }
    }
    cout << ans << '\n';
}
~~~

时间复杂度 $O(n\log n)$，空间复杂度 $O(n)$。区间长度的平方可达 $10^{18}$，用 long long 计算。

## B · 按 mex 分类计算下标子集的贡献

[题目链接](https://ac.nowcoder.com/acm/contest/143407/B)

原思路已经想到给相同的数分组。接下来枚举最终的 mex，直接数这一类的下标子集有多少个。每个 mex 为 $m$ 的子集都贡献 $m^k$。

| 值 | 选择条件 | 方案数 |
|---|---|---:|
| 每个 $x<m$ | 至少选一个值为 $x$ 的下标 | $2^{cnt[x]}-1$ |
| $x=m$ | 这一组全部不选 | $1$ |
| $x>m$ | 每个下标自由选或不选 | $2^{\#\{i:a_i>m\}}$ |

各组互相独立，因此方案数相乘。减 1 只用于必须出现的值，去掉该组全不选的方案。比 mex 大的所有下标全不选也是合法方案。

例如 $a=[1,2,2]$、$k=2$，mex 为 1 时有 4 种方案，mex 为 2 时有 1 种，mex 为 3 时有 3 种。总贡献为 $4\cdot1^2+1\cdot2^2+3\cdot3^2=35$。空集已经计入 mex 为 1 的方案。

遍历到 $m$ 时，ways 记录小于 $m$ 的每组至少选一个的方案数。先把当前组数量从 remain 扣掉，此时 remain 正好是大于 $m$ 的下标数。**先统计当前 mex 的贡献，再更新 ways**。原数组中缺失 $m$ 时，算完当前项即可停止，因为任何更大的 mex 都要求 $m$ 出现。

沿用模板中的 MOD、ll 和快速幂 qpow。

~~~cpp
void wait() {
    int n, k;
    cin >> n >> k;

    vector<int> freq(n + 2);
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;
        if (x <= n + 1) ++freq[x];
    }

    vector<ll> pow2(n + 1, 1);
    for (int i = 1; i <= n; ++i) {
        pow2[i] = pow2[i - 1] * 2 % MOD;
    }

    ll ans = 0, ways = 1;
    int remain = n;
    for (int m = 1; m <= n + 1; ++m) {
        remain -= freq[m];
        ll count = ways * pow2[remain] % MOD;
        ans = (ans + count * qpow(m, k)) % MOD;

        if (freq[m] == 0) break;
        ways = ways * (pow2[freq[m]] - 1) % MOD;
    }
    cout << ans << '\n';
}
~~~

mex 至多为 $n+1$。更大的值无需单独存频次，它们仍计入 remain，可以自由选择。时间复杂度 $O(n\log(k+1))$，空间复杂度 $O(n)$。
