# 动态规划综合训练题单

整理日期：2026-11-04。适用阶段：已经系统学过 DP，希望检验独立建模能力，并补齐不同方向的实践。

以 [AtCoder Educational DP Contest](https://atcoder.jp/contests/dp/tasks) 的 26 道题为主线，补充 CSES 的数位、轮廓线题和两道 CF 转移优化题，共 **30 道：4 道热身、20 道主练、6 道进阶选做**。题目分组与练习顺序是本题单的训练建议，不代表官方难度分级，也不把 AtCoder 字母顺序当作严格难度顺序。

你目前 CF 约 1200 分，可以直接从主练开始；进阶选做留给后续，不作为开始训练的门槛。学过某个模型后仍可能需要提示，重点检查是否能自己定义状态、解释转移和处理边界。

## 怎么练

- **第一批 8 题**：C → D → E → F → G → N → P → I。已经独立做过的可以跳过或闭卷回做。
- 接着补 M、L、O、S、Counting Numbers，再练 X、V、U、J、T、Q、Counting Tilings；后半部分有些题明显更难，不要求一遍独立完成。
- 独立思考约 30～45 分钟；卡住时先要一个提示，再继续推导。每题至少说清状态含义、转移依据、初值、答案位置和复杂度。
- 分类练完后，间隔几天打乱顺序回做，或混入 CP-31，检验能否自己识别 DP。比赛、VP 当天用补题和复盘替代额外训练。
- 完成记录只填 `独立 AC / 提示后 AC / 题解后 AC`，回做后再记 `闭卷回做通过`。笔记写一句关键收获即可，典型错题再展开。

**所有完成记录暂留空**，未查询线上账号；本地有同类代码不代表已经做过本题。本题单不附状态方程、转移公式或题解。
