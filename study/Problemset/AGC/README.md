# AGC 复盘目录

从 [AGC001](AGC001.md) 开始，到 AGC079 为止。每场一份笔记，共 78 场、234 道 A、B、C 题。场次页保留官方题面和题解入口，做题时不显示算法标签。

已有进度：[AGC018](AGC018.md) A/B/C 做出 · [AGC019](AGC019.md) A/B 做出 · [AGC020](AGC020.md) B 待补、C 待闭卷复做。

状态：`做出`＝你已反馈做出（不默认是独立 AC）；`卡住`＝尝试过但没做出；`已讨论`＝接触过思路，未确认 AC；`—`＝暂未记录。之后可直接写 `独立 AC`、`提示后 AC` 或 `待重做`。普通题只填状态，有收获的题再记一句：**我的卡点 → 下次先试什么**。
