## C：先找质量在哪里损失

操作内部核不会损失质量；操作端点核，至少损失 1。记总质量为 `sum`。

- 全部为 1：无法操作，答案为 `-1`。
- 内部存在大于 1 的核：可以连续从内部消除，把可操作性传给旁边的内部核，直到剩两个；最后损失 1，答案为 `sum-1`。
- 内部全为 1，但至少一个端点大于 1：只能从端点启动。每次给旁边的 1 增加质量后，它仍是新端点，必须继续从端点消除。共消除 `n-1` 个核，每次最少损失 1，答案为 `sum-(n-1)`。`n=2` 也符合这个公式。

之前的错误：根据“存在 1”额外扣一次，忽略了 1 可以接收邻居的质量。反例 `[1,2,1]`：拆中间得到 `[2,2]`，再拆端点得到 `[3]`。

**讨论中的修正：先前说“内部全为 1 时答案为 sum-2”不正确。**例如 `[2,1,1,1]` 只能逐步变为 `[2,1,1] → [2,1] → [2]`，总质量 5，答案 2。当前代码的 `ans-=n-2` 再输出 `ans-1` 对应正确公式。

局部验证：枚举每一步合法拆分，确认 `[2,1,1,1] → 2`、`[1,2,1] → 3`、`[2,1,1,3] → 4`、`[1,1,1] → -1`、`[6,7] → 12`。这些是小例验证，不是线上通过记录。

## D：忽略整体平移

锁住一组数，其余数全部加 1，等价于“锁住的数减 1，再全体加 1”。全体平移不影响是否相等，因此可以只分析选中元素的相对调整。

选目标值 `m`，最少费用为：

\[
\sum_i |a_i-m|
\]

取中位数即可最小。排序后：

```cpp
ll m = a[(n + 1) / 2];
ll cost = 0;
for(int i = 1; i <= n; i++) cost += abs(a[i] - m);
ll operations = a[n] - a[1];
```

操作次数的下界：原来最大、最小的两个元素，每次差值最多缩小 1。

达到下界的方法：在等价操作中，所有低于中位数的元素一起逐步增加，到达就退出；高于中位数的元素一起逐步减少。共 `(m-min)+(max-m)=max-min` 次，每个元素没有多走，费用仍最小。

之前绕远：先写复杂模拟，再二分目标值。应先化简操作，再识别绝对值之和。总费用用 `long long`；复杂度 `O(n log n)`。

## E：位置奇偶性和符号一起变化

原操作 `(x,y) → (-y,-x)`，元素每移动一格，位置奇偶性改变，符号也取反。

按原下标构造：

```cpp
b[i] = (i % 2 == 1 ? a[i] : -a[i]);
```

此时原操作在 `b` 中就是普通相邻交换，所以 `b` 可以任意排列。原数组总和对应：

\[
b_1-b_2+b_3-b_4+\cdots
\]

最大的 `(n+1)/2` 个数放加号位置，最小的 `n/2` 个数放减号位置。排序后用总和减去最小 `n/2` 个数的两倍即可；奇数长度时，加号自然多一个。

之前的错误：只在相邻和为负时操作，要求每一步立即增大总和。反例 `[-1,1,1,-1]` 会停在 0，但可以先操作中间得到全 -1，再分别操作前后两对得到全 1，答案为 4。

注意：先按原下标变号，再排序；答案用 `long long`。复杂度 `O(n log n)`。

## F：推导已讨论，待自己实现

对 `x≥y`，令：

\[
d(x,y)=\left(\left\lfloor\frac{x}{y}\right\rfloor-1\right)y,
\qquad x\bmod y=x-y-d(x,y)
\]

相邻差求和抵消后有 `m=a[1]-a[n]-Σd`。由首尾范围知 `Σd` 只能为 0 或 1。

合法序列从 `m+2` 开始，普通转移满足 `y≤x<2y`，最后停在 2；也可以通过唯一特殊转移 `2→1`，之后一直填 1。

令 `dp[i][v]` 为长度 i、末尾为 v 的方案数，初始化 `dp[1][m+2]=1`：

- `v≥2`：从上一层的区间 `[v,min(m+2,2v-1)]` 求和。
- `v=1`：`dp[i][1]=dp[i-1][1]+dp[i-1][2]`。
- 答案：`dp[n][1]+dp[n][2]`，对 `998244353` 取模。

用前缀和优化区间求和，时间 `O(nm)`，滚动数组空间 `O(m)`。尚未实现验证，不记为已掌握。
