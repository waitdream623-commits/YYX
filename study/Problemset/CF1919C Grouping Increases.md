# CF1919C · Grouping Increases

2026-11-14。当前尝试：反转数组，取一条最长不降子序列作为零代价组，再统计剩余序列的下降次数。尚未记录 AC。[题面](https://codeforces.com/problemset/problem/1919/C)

## 原实现的问题

- vector 与恢复出的下标均为 0 下标，遍历必须为 `0 <= i < n`；原 `rep(i,1,n)` 漏掉 a[0] 并访问越界的 a[n]。
- upper_bound 求的是最长不降子序列，允许相等，这与反转后的零代价要求一致，问题不在此处。
- 选最长的零代价组不保证剩余组的代价最小，两组必须联合考虑。

反例原数组 `[1,2,2,1,2]`，反转后 `[2,1,2,2,1]`。当前恢复得到下标 `[1,2,3]`，对应 `[1,2,2]`，剩余 `[2,1]` 产生一次下降，算出 1。原数组可分为 `[1,1]` 和 `[2,2,2]`，两组均无上升，最优为 0。此反例针对修复下标后的算法；原代码因越界不能保证具体输出。

## 只维护两组的末尾

直接按原数组顺序处理。设两个末尾为 x、y，空组用 INF 表示，每轮先调整为 x ≤ y。

| 当前值 v | 操作 |
| --- | --- |
| v ≤ x | 替换 x，不增加代价，保留更大的 y |
| x < v ≤ y | 替换 y，不增加代价 |
| v > y | 两边都会增加一次代价；答案加一，替换 x，保留更大的 y |

两个都能无代价接入时，优先使用较小末尾，保留较大末尾的接纳范围。两个都必须付费时，替换较小末尾后得到的末尾对为 `(y,v)`，比替换较大末尾得到的 `(x,v)` 更有利。中间情形有无代价的放法，选择它。

时间 O(n)，额外空间 O(1)。本次用小规模枚举二分组找到并核对了上述反例，未进行完整提交验证。
