## B · 思路正确，邻居访问越界

[官方题面](https://codeforces.com/contest/2000/problem/B)保证座位编号在 1..n，输入互不相同。先记录首个乘客，之后检查相邻位置是否已坐人的思路符合题意。

错误在 `vector<bool> vis(n+1,0)`：合法下标为 0..n，却可能在 a=n 时访问 vis[a+1]，即 vis[n+1]。

```text
1
3
1 3 2
```

第一个乘客坐 1，接着检查座位 3：vis[2] 为 false，短路或运算继续读取 vis[4]，但容器长度只有 4，发生越界。正确答案是 NO。开启 `-D_GLIBCXX_DEBUG` 后，本地原代码明确报出下标 4 超出长度 4。

最小修复：`vector<bool> vis(n+2,0);`，让 0 和 n+1 作为永远为空的哨兵。也可以访问前显式判断 a>1、a<n。

普通运行中越界不一定崩溃；vector<bool> 按位存储，读到容器逻辑范围之外仍可能碰巧落在已分配存储中，不能据“小样例结果正常”断定安全。尚未取得线上 test 11 的完整输入，因此确认的是本地可复现缺陷，不臆测其具体数据。

## E · 大数配大贡献，但回字形不保证贡献递减

[官方题面](https://codeforces.com/contest/2000/problem/E)统计所有 k×k 子正方形内身高之和。用户赛时想到“更大的放中间，让它多次被计算”，方向正确。需要继续把“多次”量化成每格覆盖次数，不能直接假设几何回字形就是最优顺序。

若格子 (i,j) 被 c[i][j] 个 k×k 正方形覆盖，那么该格身高 h 对总答案的贡献恰好为 h×c[i][j]。空格身高视为 0，因此问题转成身高与格子权重的配对。

### 行列独立计数

能覆盖第 i 行的正方形，其起始行 u 必须同时满足：

$$
1\le u\le n-k+1,\qquad i-k+1\le u\le i.
$$

所以起始行的选择数为：

$$
row(i)=\min(i,n-k+1)-\max(1,i-k+1)+1
      =\min(i,n-i+1,k,n-k+1).
$$

同理 col(j)=min(j,m-j+1,k,m-k+1)。起始行和起始列可以自由组合：

$$
\boxed{c[i][j]=row(i)\times col(j).}
$$

例如 n=m=9、k=5：格子 (1,5) 的权重为 1×5=5，格子 (2,2) 的权重为 2×2=4。虽然 (2,2) 位于更内一圈，它的贡献次数却更少。因此从中心逐圈填充，可能先将大数放到权重 4 的格子，而把小数放到权重 5 的格子，浪费收益。

### 为什么两个数组同序排序

若 h1≥h2、c1≥c2，将大身高放大权重比交叉配对多出的收益为：

$$
h_1c_1+h_2c_2-h_1c_2-h_2c_1=(h_1-h_2)(c_1-c_2)\ge0.
$$

因此将所有格子权重与所有身高分别降序排序，取最大的 w 个权重依次配对。无需真的构造网格。

```cpp
void solve() {
    int n, m, k, w;
    cin >> n >> m >> k >> w;
    vector<long long> h(w), weight;
    for (auto &v : h) cin >> v;
    weight.reserve(n * m);
    for (int i = 1; i <= n; ++i) {
        long long row = min({i, n - i + 1, k, n - k + 1});
        for (int j = 1; j <= m; ++j) {
            long long col = min({j, m - j + 1, k, m - k + 1});
            weight.push_back(row * col);
        }
    }
    sort(h.rbegin(), h.rend());
    sort(weight.rbegin(), weight.rend());
    long long ans = 0;
    for (int i = 0; i < w; ++i) ans += h[i] * weight[i];
    cout << ans << '\n';
}
```

时间 O(nm log(nm)+w log w)，空间 O(nm+w)。使用 long long 存权重、身高乘积及答案。当前 E 本地草稿将身高排序范围写为 n，实际身高数量是 c（或 w），若继续使用该草稿，也应改为按实际人数排序。

**大的往中间放，这个方向对；但“从中间逐圈扩散”的顺序不一定对。** 同一圈里，不同位置被统计的次数可能差很多。

例如 \(9\times9\) 网格，正方形边长 \(k=5\)，各格被统计的次数是：

```
 1  2  3  4  5  4  3  2  1
 2  4  6  8 10  8  6  4  2
 3  6  9 12 15 12  9  6  3
 4  8 12 16 20 16 12  8  4
 5 10 15 20 25 20 15 10  5
 4  8 12 16 20 16 12  8  4
 3  6  9 12 15 12  9  6  3
 2  4  6  8 10  8  6  4  2
 1  2  3  4  5  4  3  2  1
```

看这两个位置：

- `(3,3)`：更内一圈的角，统计 **9 次**。
- `(2,5)`：更外一圈的中间，统计 **10 次**。

如果按圈填满内圈再填外圈，就会先填权重 **9**，后填权重 **10**，把更大的数放错位置。

所以你的想法可以保留：**从中心向外扩散，但每一步必须选“剩下的格子里，被统计次数最多的”**，不能只按圈数或距离判断。直接把次数排序，就是最省事的实现。

## F · Color Rows and Columns：矩形内贪心，矩形间分组背包

[题目链接](https://codeforces.com/contest/2000/problem/F)。每次涂一个格子，涂满一行或一列各得 1 分，要求至少获得 k 分，最小化涂色次数。本节为赛后辅助推导，尚无 F 在线 AC 记录。

### 为什么每次选短边最小的矩形不对

短边最小，只能说明当前拿下一分便宜，不能保证总共拿若干分最便宜。随着矩形被涂色，后续每分的新增代价会下降；最后一个格子还会同时完成一行和一列，获得 2 分。因此先支付稍贵的代价，可能解锁后面的便宜收益。

用户提供的样例：

```text
1
4 18
5 4
8 5
8 3
6 2
```

按短边排序的原代码先填满 6×2，花 12 次获得 8 分，然后从 8×3 获取剩余 10 分，花 24 次，总共 36 次。

更优分配为：

| 矩形 | 操作 | 得分 | 涂色次数 |
|---|---|---:|---:|
| 6×2 | 全部涂满 | 8 | 12 |
| 5×4 | 全部涂满 | 9 | 20 |
| 8×3 | 涂满一列，含 3 格 | 1 | 3 |
| 8×5 | 不动 | 0 | 0 |
| 合计 | | 18 | 35 |

对比每多拿一分的新增代价：

```text
3×8 的前 10 分：3,3,3,3,3,3,2,2,1,1，合计 24。
4×5 的全部 9 分：4,4,3,3,2,2,1,1,0，合计 20。
```

最后的 0 表示最后一次涂色同时获得两分，不是实际存在一次零操作的涂色。用 4×5 拿 9 分，再从 3×8 拿 1 分，只需要 20+3=23 次，比单独从 3×8 拿 10 分省一次。

### 单个矩形：预处理每种分数的最小代价

定义 cost[t] 为当前矩形获得至少 t 分的最少涂色次数，cost[0]=0。

对于剩余 a×b 的矩形，设 a≤b，涂满一列需要 a 次，之后剩余 a×(b−1)。不断选择当前较短的边作为新增涂色次数。直观上，已经涂满的行列会相互重叠，先消去较长方向的一条，使剩余两边更接近，能降低总涂色量。

也可以用公式理解：涂满 r 行、c 列需要 rb+ca−rc 个格子。固定 r+c 时，相当于让剩余矩形 (a−r)(b−c) 的面积最大，因此应让剩余两边尽量接近。

例如 2×3 的 cost 为：

| 至少获得的分数 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| 最少涂色次数 | 0 | 2 | 4 | 5 | 6 | 6 |

注意按“至少”定义，最后两个状态可以相等，避免误认为必须恰好得到每一种分数。

### 多个矩形：分组背包

定义 dp[j] 为已处理矩形获得至少 j 分的最少涂色次数。初始 dp[0]=0，其他为 INF。

枚举当前矩形贡献至少 t 分：

```cpp
ndp[j] = min(ndp[j], dp[max(0, j - t)] + cost[t]);
```

每个矩形只选一个贡献方案，使用独立的 ndp，避免把同一个矩形反复使用。只需要保留 0..k 分的状态。

```cpp
void solve() {
    int n, k;
    cin >> n >> k;
    const int INF = 1e9;
    vector<int> dp(k + 1, INF);
    dp[0] = 0;

    for (int i = 0; i < n; ++i) {
        int a, b;
        cin >> a >> b;
        int total = a + b;
        vector<int> cost(total + 1);
        int points = 0, used = 0;

        while (a > 0 && b > 0) {
            if (a > b) swap(a, b);
            used += a;
            --b;
            cost[++points] = used;
        }
        // 最后一格同时完成一行、一列，再补一个分数状态。
        cost[++points] = used;

        vector<int> ndp(k + 1, INF);
        for (int j = 0; j <= k; ++j) {
            for (int t = 0; t <= min(total, k); ++t) {
                ndp[j] = min(ndp[j],
                             dp[max(0, j - t)] + cost[t]);
            }
        }
        dp.swap(ndp);
    }
    cout << (dp[k] == INF ? -1 : dp[k]) << '\n';
}
```

时间 O(Σ(a_i+b_i)+nk²)，额外空间 O(k+max(a_i+b_i))。题目中 a_i,b_i≤100、k≤100，所有测试的 n 总和不超过 1000。

复做重点：区分“单个对象内部每步最优”和“多个对象之间如何分配资源”。当前最便宜的下一步，不足以证明全局贪心成立。
