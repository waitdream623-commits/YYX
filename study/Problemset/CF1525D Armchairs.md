# CF1525D · Armchairs

2026-11-15。当前尝试按人的位置从左到右，为每个人分配最近的剩余空位；用户反馈未通过全部测试。[官方题面](https://codeforces.com/problemset/problem/1525/D)

## 最近空位贪心的反例

```text
6
0 0 1 1 1 0
```

人位于 3、4、5，空位位于 1、2、6。

| 方法 | 配对 | 总距离 |
| --- | --- | --- |
| 原贪心 | 3→2，4→6，5→1 | 1+2+4=7 |
| 最优 | 3→1，4→2，5→6 | 2+2+1=5 |

当前人局部少走一步，可能让后面的人多走数步。这个反例中没有距离并列，修改平局时的左右选择也无法解决。本次用小规模枚举所有目标空位组合找到了并核对了该反例。

## 保证有序匹配，但用 DP 决定使用哪些空位

设原有人的位置依次为 p[1..m]，原空位依次为 q[1..z]。一维绝对值距离满足交换不等式：对 p1≤p2、q1≤q2，有 `|p1-q1|+|p2-q2| ≤ |p1-q2|+|p2-q1|`，所以总能选到一个按位置顺序匹配的最优方案。

`dp[i][j]`：前 i 个人使用前 j 个空位完成安置的最小代价。

```text
dp[i][j] = min(dp[i][j-1], dp[i-1][j-1] + abs(p[i]-q[j]))
```

分别表示跳过第 j 个空位，以及把第 i 个人分配到第 j 个空位。初始化 dp[0][j]=0，i>0 时 dp[i][0]=INF。答案 dp[m][z]。时间 O(mz)，滚动优化可将空间压到 O(m)，按空位枚举时人数必须倒序更新，防止同一个空位被用两次。

原贪心中 a[i] 保持为 1 可以理解为把原有座位标记为永不可用；这是符合最终要求的建模，并非失败原因。左右线性找空位的最坏复杂度为 O(n²)，本次反例暴露的是正确性问题。
