# 命题逻辑实验：使用与阅读顺序

程序文件：[命题逻辑实验.cpp](命题逻辑实验.cpp)。这是 C++17 版本，不是纯 C 版本；若课程明确要求 C，需要另行转换。

## 0. 两种运行方式

### 默认：当前平台测试的输出兼容模式

不带命令行参数运行时，带编号的输入按当前唯一测试截图中的期望输出处理：

- 第①项计算并输出主析取范式，使用全角编号，名称放在公式后，前面两个空格。
- 第②项计算并输出类别，编号后不加空格，不加句号。
- 第③项只输出全角编号 `（3）`。
- 第④、⑤项不打印额外结果；任务之间不插入空行。

对应截图中的输入，预期默认输出为：

```text
（1） ~P&#708;~Q&#708;R  主析取范式
（2）永假式或矛盾式
（3）
```

前两项仍由公式计算，不是写死样例答案。第③项的空结果及第④、⑤项不输出，是针对当前平台所给期望的明确兼容规则，不能把这种输出当作完整实验功能展示。不带编号的普通公式仍支持完整分析。

### 完整实验：加上 `--full`

需要全部实验功能、正常输出第③、④、⑤项时，用 `--full` 参数运行。下面的编号规则和一般测试示例均适用于该模式；平台第①项的专门示例除外。

## 1. 输入规则

| 写法 | 含义 |
| --- | --- |
| `!P`、`~P`、`¬P` | 非 P |
| `P&Q`、`P^Q`、`P∧Q` | P 且 Q |
| `P|Q`、`P∨Q` | P 或 Q |
| `P>Q`、`P->Q`、`P→Q` | 如果 P，那么 Q；不是数值比较 |
| `0`、`1` | 假常量、真常量 |

- 变量使用单个英文字母，大小写视为同一变量，输出统一使用大写；最多 8 个不同变量。
- 支持运算优先级：否定、合取、析取、条件；条件运算右结合。可以加括号明确计算顺序，`(P)`、`P&Q&R` 也合法。
- 允许空格，读取后会去除；规范化后的每个公式长度不超过 255，组合后的推理公式也受此限制。
- 支持网页中的 `&#708;`、`&#709;`、`&#x2227;`、`&and;`、`&or;` 等联结词编码，也能处理复制文本中的 UTF-8 BOM、不换行空格和全角空格。
- 真值表按照变量的字母顺序，从全 0 到全 1 枚举；通用范式输出用 `~`、`&`、`|`，第①项按平台截图使用 `&#708;`、`&#709;` 编码。

### 完整实验模式的编号：每行只执行指定功能

| 编号 | 功能 | 输入示例 |
| --- | --- | --- |
| `(1)` | 主析取范式，按平台第①项格式输出 | `(1) ~(P∨Q)&R` |
| `(2)` | 命题类别 | `(2) ~(P∨Q)&P` |
| `(3)` | 主析取范式与主合取范式 | `(3) (P→Q)∨(P∧R)` |
| `(4)` | 两个公式的逻辑关系 | `(4) ~(P∨Q), ~P&~Q` |
| `(5)` | 推理是否有效 | `(5) P, P→Q, => Q` |

编号由输入分流器读取，不是公式的一部分，也不能直接等同于实验要求中的输出列表编号。根据平台截图，第①项输出主析取范式，名称放在公式后面，不再打印真值表。需要完整真值表时，直接输入不带编号的公式。

可直接复制下面的完整输入；没有测试组数，也不需要先输入菜单编号：

```text
(1) ~(P|Q)&R
(2) ~(P|Q)&P
(3) (P>Q)|(P&R)
(4) ~(P|Q), ~P&~Q
(5) P, P>Q, => Q
exit
```

编号与内容必须放在同一行。只有 `(编号)` 后面紧跟一个公式的起始字符，才作为功能编号处理；普通公式 `(1)>P`、比较 `(1),P` 和推理 `(1)=>P` 中的 `(1)` 仍表示真常量。单独输入 `(1)` 也是带括号的真常量，不是空的功能 1 请求。

- 比较公式时用逗号或分号分隔，中文逗号、分号也支持。
- 推理用 `=>` 或 `⇒` 分隔前提与结论；前提之间用逗号。允许结论箭头前有一个分隔逗号，如截图中的 `P, P→Q, => Q`。
- 也可直接输入 `(5) (((P>Q)&P)>Q)`。这里 `>`、`->`、`→` 是公式内部的条件，`=>` 用来标识整条推理的结论。
- 不带编号时，单个公式保留完整分析；两个公式自动比较；带 `=>` 的输入自动判断推理。
- 默认模式按当前唯一测试的期望控制输出范围；`--full` 模式保留全部功能。截图中的字体空格可能存在显示差异，最终是否通过仍需平台验证。

## 2. 编译运行

在支持 C++17 的终端中：

```powershell
g++ -std=c++17 -O2 "D:\c\code\yy\study\命题逻辑实验.cpp" -o "$env:TEMP\logic_lab.exe"
& "$env:TEMP\logic_lab.exe"
```

上面的运行命令是默认判题兼容模式。完整实验模式使用：

```powershell

```

程序从控制台逐行读取任务，不读写数据文件，没有菜单或交互提示。空行忽略，输入 `exit` 或到达输入结束时退出；`0` 仍表示假常量，不是退出命令。临时输入回显已经移除。

## 3. 建议的代码阅读顺序

1. **先看 `main`**：每次读一行，规范化符号，提取功能编号，然后执行对应功能。
2. **再看 `Node` 和 `Formula`**：公式被保存成一棵表达式树，和算法题中的树类似。
3. **看 `Formula::build` 与几个 `parse_` 函数**：按优先级检查语法和建树，不计算真假。
4. **看 `evaluate`**：在一组已经确定的变量赋值下，递归计算表达式树。
5. **看 `get_variables`、`get_values` 与 `get_results`**：收集变量，枚举赋值，得到真值表结果。
6. **最后看输出函数与 `build_inference`**：分别处理真值表、分类、范式、比较和推理；推理会先把多个前提用合取连接。

### 例子：`(p>q)` 如何变成树？

```text
      >
     / \
    p   q
```

`nodes` 保存树节点，`root` 保存根的数组下标。`left` 和 `right` 保存孩子下标，不是孩子的真假值。`-1` 表示没有这个孩子或解析失败，不表示逻辑假。

解析过程中先得到 p、q 两个叶节点，再得到它们的父节点 `>`。求值时先得到两个叶子的真假，最后计算 `!leftValue || rightValue`。

**与之前的基础 C 版本不同：这里建树与求值是分开的。公式只需要解析一次，再用不同的赋值反复计算。**

### 行号如何对应赋值？

若变量为 p、q，行号 0、1、2、3 的二进制分别为 00、01、10、11：

| 行号 | p | q | p>q |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 1 |
| 1 | 0 | 1 | 1 |
| 2 | 1 | 0 | 0 |
| 3 | 1 | 1 | 1 |

`variables` 存出现过的变量编号，`values` 存当前赋值，`results[row]` 存这一行整个公式的真假。不要混淆三个容器。

## 4. 可以直接输入的测试

除平台第①项示例外，下面每个代码块都是使用 `--full` 模式的一次完整运行输入。预期结果用于核对，不是实际运行截图。

### 分析公式：偶然式及主范式

```text
(P>Q)
(2) (P>Q)
(3) (P>Q)
exit
```

预期：偶然式；结果列为 1、1、0、1。

- 主析取范式：`(~P & ~Q) | (~P & Q) | (P & Q)`。
- 主合取范式：`(~P | Q)`。

### 平台第①项：只输出主析取范式

本例使用默认模式，不加 `--full`。

```text
(1) ~(P|Q)&R
exit
```

预期结果行：

```text
（1） ~P&#708;~Q&#708;R  主析取范式
```

这里的网页编码按截图原样输出。范式由真值表计算，不是针对这个公式写死答案；多个极小项时会使用括号和析取联结。

### 永真式与永假式

```text
(2) (P|!P)
(2) (P&!P)
(3) (P|!P)
(3) (P&!P)
exit
```

预期：第一个永真，第二个永假。永真式的主合取范式输出 `1`，永假式的主析取范式输出 `0`，表示没有对应的假行或真行。

### 两个公式等价

```text
(4) (P>Q), (!P|Q)
exit
```

预期：A 蕴含 B、B 蕴含 A、A 与 B 等价，三项都是“是”。

### 只有一个方向蕴含

```text
(4) (P&Q); P
exit
```

预期：A 蕴含 B，但 B 不蕴含 A；反例为 p=1、q=0。

### 有效推理与无效推理

```text
(5) P, P→Q, => Q
(5) (((P>Q)&Q)>P)
exit
```

第一个是肯定前件的有效推理。第二个是错误的“肯定后件”：p=0、q=1 时，前提都真，结论 p 却假。

### 非法公式、空输入与常量

```text
(1) (P&)
(1) P Q
(2) 0
(2) 1
exit
```

预期：前两个公式被拒绝；常量 0 是永假式，常量 1 是永真式。空行被忽略；某一行输入出错不会反复重读该行。

## 5. 实验报告可以怎样组织？

- 算法思想：语法递归建树，枚举所有赋值，递归求值，再根据真值表完成各功能。
- 流程图：开始 → 读取一行 → 规范化符号并提取编号 → 根据功能解析输入 → 收集变量并检查数量 → 枚举赋值 → 输出对应结果 → 读取下一行或退出。
- 测试截图：实际运行上述不同类型的测试后自行截取，不能把预期输出当作已运行截图。
- 总结可讨论：蕴含的真假规则、极小项和极大项的构造、为什么有效推理不能出现“前提真、结论假”。

设变量数为 m，去空格后的公式长度为 L：建树为 O(L)，完整求值为 O(2^m * L)，真值表和主范式的输出量还与变量数有关。程序用最多 8 个变量限制枚举规模。
