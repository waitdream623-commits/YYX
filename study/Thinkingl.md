class Solution {
public:
    int mincostTickets(vector<int>& days, vector<int>& costs) {
        int n = days.back();

        unordered_set<int> st(days.begin(), days.end());

        vector<int> dp(n + 1, 0);

        for (int i = 1; i <= n; i++) {

            // 今天不旅行
            if (!st.count(i)) {
                dp[i] = dp[i - 1];
            }

            // 今天旅行
            else {
                dp[i] = min({
                    dp[i - 1] + costs[0],
                    dp[max(0, i - 7)] + costs[1],
                    dp[max(0, i - 30)] + costs[2]
                });
            }
        }

        return dp[n];
    }
};

## 递归
5）master公式
- a. 所有子问题规模相同的递归才能用master公式，T(n) = a * T(n/b) + O(n^c)，a、b、c都是常数
- b. 如果log(b,a) < c，复杂度为：O(n^c)
- c. 如果log(b,a) > c，复杂度为：O(n^log(b,a))
- d. 如果log(b,a) == c，复杂度为：O(n^c * logn)
- 6）一个补充
- T(n) = 2\*T(n/2) + O(n\*logn)，时间复杂度是O(n \* ((logn)的平方))，证明过程比较复杂，记住即可

## 滑动窗口
- 适用
滑动窗口：维持左、右边界都不回退的一段范围，来求解很多子数组（串）的相关问题
滑动窗口的关键：找到 范围 和 答案指标 之间的 单调性关系（类似贪心）
  - 如果不达标只能往右扩
- 滑动过程：滑动窗口可以用 简单变量 或者 结构 来 维护信息
求解大流程：求子数组在 每个位置 开头 或 结尾 情况下的答案（开头还是结尾在于个人习惯）
注意：
滑动窗口维持最大值 或者 最小值的更新结构：**单调队列**

## 单调栈

### 适用
- 单调栈最经典的用法是解决如下问题：
- 每个位置都求：
- 0）当前位置的 左侧比当前位置的数字小，且距离最近的位置 在哪
- 1）当前位置的 右侧比当前位置的数字小，且距离最近的位置 在哪
- 或者
- 每个位置都求：
- 0）当前位置的 左侧比当前位置的数字大，且距离最近的位置 在哪
- 1）当前位置的 右侧比当前位置的数字大，且距离最近的位置 在哪
- 用单调栈的方式可以做到：求解过程中，单调栈所有调整的总代价为O(n)，单次操作的均摊代价为O(1)
- 注意：这是单调栈最经典的用法，可以解决很多题目
- 注意：单调栈可以和很多技巧交叉使用！比如：动态规划+单调栈优化
- 单调栈过程详细图解：
- 1，数组无重复值的情况
- 2，数组有重复值的情况

### 想法
- 存下标
- 实现是栈按照大小排好序，当该点被遗弃时，更新该点左右的值
- 对于有重复值，来的值与该点相同，该点弹出，记录左右，最后逆序遍历，如果右边点与本身相同，更新为相同点的右边(必定更新完)想不通图解
- 处理有重复值情况，条件怎么更新
- 左神一次遍历找到该点左右距离最近的大于值或者小于值，在于第一次遇到不符合规定，更新被弹出值的左右边界(https://leetcode.cn/problems/largest-rectangle-in-histogram/)
  - 例如，求该点的小于他的值，此时栈维持单调递增，该点栈下就是距离他最近的小于他的值，右边呢，在遇到一个点不满足单调递增时，要求他弹出，该点就是他的右边界
  - 对于有重复值，先弹掉，正常更新，后续逆序遍历一遍，如果边界值与本身相同，索引找相同值(该点一定更新到正确值了)
- 对于两次遍历版本，每次遍历找到一侧大于/小于该点距离最近的值
  - 依照去除不满足点，取栈头
  - 依照移除无用数据原则，移除不满足，剩余头部就是满足的
  - 例如 求大于该点
    - 求左边，正序遍历建立：单调递增还是递减，想着如果x加入，不会影响后续，x一定大于前面值，所以建立单调递减，这时下一个点小于x，直接取x位置(前面被踢掉的点一定比该点小，表示，后续的点如果小于被踢掉的点，一定小于x)
  - 对于右边，逆序遍历一遍同样操作
  - 对于重复值，直接移除，对于栈中重复点，依赖他更新的点此时已经弹出，不在需要保留，后续如果需要他也有新进重复值顶替，因此弹出
- 对于遍历完数组，栈内剩余值怎么处理
  - 取决于题目：若求某侧最近更小/更大，栈里剩余元素在该侧没有答案，填哨兵值即可。
