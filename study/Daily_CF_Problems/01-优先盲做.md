# 优先盲做：1300–1700

[总入口](README.md) · [1700 及以下全集](02-全集-1700及以下.md)

**第一轮只做四题：`02 → 05 → 06 → 13`。** 觉得启动困难，先拿 `01` 热手。下面的其余题留着轮换，每个已有的 CF 训练时段做一题就行；和之前的 DP 题单二选一，不加任务量。

选题避开了这次能查到的你的公开提交和已有题单中的重复题。若看到你线下做过的，直接换一题。盲想 30～45 分钟后还没有方向，可以先写下一个猜想，再只看对应的一条提示；复盘记「卡在哪 → 下次先检查什么」一句即可。
