## 分数口径

| 类型 | 题数 | 分档依据 |
| --- | ---: | --- |
| CF 普通题，API 有评分 | 968 | [Codeforces `problemset.problems`](https://codeforces.com/apiHelp/methods#problemset.problems) 的 `rating` |
| CF 普通题，API 未核对到评分 | 3 | 用仓库每日表：`CF398B *1700`、`CF396B *1800`、`CF485E 2600` |
| Gym | 736 | 用仓库每日表，不称作 CF 官方评分 |
| 小羊杯 | 19 | 单列；Round 2 保留出题人分档，不换算为 CF 分数 |

同题的多份仓库标注会全部保留。`CF163C` 仓库标注有 2100／2200，按官方 2100 分档；`GYM103708L` 和 `GYM105946A` 均有 `*1900`／`*2000` 两种仓库标注，分别按每日表的 1900 和 2000 分档。`CF1936C` 的 `*2400` 与 `2400` 是同一个数值，两个原始写法都保留。

## 原编号与实际题面入口

题号按题面路径归一，题解链接用仓库里实际存在的文件名。原日期链接仍会打开原表，可能看见原编号。以下是容易影响查找的差异：

| 仓库显示或旧链接 | 本索引入口 | 依据 |
| --- | --- | --- |
| `CF802B` / `CF802K` / `CF802L` | [CF802A2](https://codeforces.com/problemset/problem/802/A2) / [CF802J2](https://codeforces.com/problemset/problem/802/J2) / [CF802J3](https://codeforces.com/problemset/problem/802/J3) | 官方现用题号，和原题内容及题解对应；官方 API 有评分 |
| `CF485E` 的 `/contest/` 路径 | [CF485E](https://codeforces.com/problemset/problem/485/E) | 题号不变，使用已核实的 `/problemset/` 入口 |
| `CF922B` / `CF436E` / `CF790A3` / `CF343` | `CF992B` / `CF436C` / `CF690A3` / `CF343C` | 原表链接和解答对应这些题号 |
| 专题表 `CF491B` | `CF571B` | 专题链接实际指向 `571/B` |
| `GYM104852D` / `GYM104535E` / `GYM106174C` | `GYM104852/4` / `GYM104535/911.E` / `GYM106174/3` | 保留 Gym 题面的数字或复合下标 |
| `GYM106247B` / `GYM106247D` | `GYM106247/2` / `GYM106247/4` | 同上 |
| `GYM104873I` / `GYM105122J` | `GYM104871I` / `GYM105112J` | 原表链接实际指向这两个比赛 |
| 每日表及部分专题表的 `GYM106631F` | `GYM106631A` 或 `GYM106631I` | 按原链接区分两个不同题目，不把两题合成 `F` |
| 2026-05-25 与 2026-05-26 都写 `GYM105873G` | [GYM105873G · Generating Polygons](https://codeforces.com/gym/105873/problem/G) 与 [GYM105873H · Huron Designs](https://codeforces.com/gym/105873/problem/H) | 5 月 26 日的提示、`cf105873h.md` 题解及官方题面属于 H；专题 DP、位运算里的同条记录也归到 H |

另有题解文件名沿用旧编号或误拼，如 `CF533B → cf533c.md`、`GYM106039J → cf106035j.md`、`GYM103185B → cf103815b.md`、`GYM106457F → cf106463f.md`、`GYM103150C/D → cf103510c/d.md`、`GYM106208F → cf106280f.md`、`GYM106611K → cf106611lk.md`。全集按题面列题、按实际文件路径挂题解。
