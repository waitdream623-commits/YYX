# 树形 DP 知识概要

## 什么是树形 DP？

在树结构上做 DP，**从叶子向上递推**（DFS 后序遍历）。

```
核心模式：先递归孩子 → 用孩子的结果算自己
```

---

## 三大基础模型

### 1. 最大独立集（P1352 没有上司的舞会）

**问题**：选一些节点，不能同时选父子，求最大权重和。

**状态**：
- `dp[u][0]` = 不选 u 时，子树最大价值
- `dp[u][1]` = 选 u 时，子树最大价值

**转移**：
```
dp[u][0] = sum max(dp[v][0], dp[v][1])   // 不选 u，孩子可选可不选
dp[u][1] = a[u] + sum dp[v][0]            // 选 u，孩子必须不选
```

**答案**：`max(dp[root][0], dp[root][1])`

---

### 2. 树形背包（P2014 选课 / P1273 有线电视网）

**问题**：在树上选节点，依赖关系（选子必须先选父），背包容量限制。

**状态**：
- `dp[u][j]` = 从 u 的子树中选 j 个节点的最大价值

**转移**（树形背包的 O(n²) 经典写法）：
```cpp
for (int v : son[u]) {
    dfs(v);
    for (int j = size[u]; j >= 0; j--)           // 倒序，类似 01 背包
        for (int k = 0; k <= size[v]; k++)
            dp[u][j + k] = max(dp[u][j + k], dp[u][j] + dp[v][k]);
}
```

**关键**：二维 DP + 倒序枚举（和背包一样，防止重复选）。

---

### 3. 树的直径 / 最长路径（无向树）

**问题**：求树上最远两点距离。

**思路**：DFS 返回以 u 为起点的最长向下距离，在递归过程中用两个最长子路径更新答案。

```cpp
int ans = 0;
int dfs(int u, int fa) {
    int d1 = 0, d2 = 0;       // 最长的两条向下路径
    for (int v : adj[u]) {
        if (v == fa) continue;
        int d = dfs(v, u) + 1;
        if (d > d1) d2 = d1, d1 = d;
        else if (d > d2) d2 = d;
    }
    ans = max(ans, d1 + d2);  // 经过 u 的最长路径
    return d1;                // 返回 u 能到达的最远距离
}
```
