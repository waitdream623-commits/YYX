## 错因分类标签

| 标签 | 含义 |
|------|------|
| `边界` | 数组越界、n=1 特判、负数/零处理 |
| `类型` | int 溢出、忘记 long long、浮点精度 |
| `初始化` | 多测没清空、默认值不对、INF 设置错误 |
| `逻辑` | 算法思路错误、条件漏判、推导不严密 |
| `实现` | 思路对但代码写错、变量名混淆、循环边界 |
| `时间` | 超时，复杂度假了 |
| `读题` | 漏看条件、理解偏差 |
