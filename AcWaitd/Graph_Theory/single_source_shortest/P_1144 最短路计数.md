# 题解
## 解题思路
- 从1开始求解到各个点最短距离条数，且无边权，根据数据量，使用堆优化dijkstra
- 对于条数，在距离相同时候，加上，松弛操作时候替换
- 重边也要加入，也算一条路
- 综上，我们需要**dist[N]** 存储距离，方便比较，需要 **f[N]**记录每个点方案数

---
## 错误分析
1. st 数组原本的作用是什么？
在标准带权图的 Dijkstra 算法中，由于边权大小不一，一个节点可能会被多次更新。
比如：先发现一条距离为 10 的路径（压入队列 {10, x}），后来又发现一条距离为 5 的捷径（再次压入队列 {5, x}）。
当 {5, x} 出队并处理完后，那个历史遗留的 {10, x} 还在队列里。当它出队时，我们必须用 if (st[a]) continue; 来拦截它，防止重复遍历它的边，否则会导致严重超时（TLE）。
2. 带权图必须加回来： 如果以后遇到边权不一样（比如有的是 2，有的是 5）的题目，必须把 st[a] = 1; 和 if(st[a]) continue; 加回来，否则绝对会 TLE。
3. 杀鸡焉用牛刀： 既然这道题边权全是 1，你其实根本不需要用到 priority_queue（每次插入还要 $O(\log N)$ 的时间）。直接使用最普通的 queue<int> q; 跑 BFS（广度优先搜索） 就可以了。BFS 天然就能解决边权为 1 的最短路，而且时间复杂度是绝对线性的 $O(N+M)$，跑得比 Dijkstra 更快！

## 松弛操作更新f
假设你之前用别的路线走到了 b，记录下 dist[b] = 10，并且记录了有 5 种走法（f[b] = 5）。
但是现在，你通过节点 a 发现了一条新路，算下来距离竟然只有 8！
既然发现了距离为 8 的路，那之前距离为 10 的那 5 种走法就全部作废了（它们不再是“最短”路）。你必须把旧的 f[b] 清空。
那么新的 f[b] 是多少呢？既然现在走到 b 的最短路必须经过 a，那么走到 a 有多少种最短走法，走到 b 就有多少种最短走法。所以，f[b] 直接继承 f[a] 的值，这就是 f[b] = f[a]; 的根本原因。
~~~cpp
        if(dist[a]+1<dist[e])
        {
          dist[e]=dist[a]+1;
          f[e]=f[a];
          q.push({dist[e],e});
        }
        else if (dist[a]+1==dist[e])//此处为else if 如果为if,上面不能改f
        {
          f[e]=(f[e]+f[a])
        }
~~~
