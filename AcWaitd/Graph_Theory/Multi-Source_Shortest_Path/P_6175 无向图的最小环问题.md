# 题解

## 分析
- 最小环起点不固定，使用Floyd
- 存在很多环，使用ans记录最小环边权和
- 环需要满足起点终点一致
- 算法思路：在Floyd算法的计算过程中，我们可以取小于k的两个节点i,j(c此时f[i][j]已经更新完毕）若i,j与k之间均有边，则存在一个可能的最小环 i-j-k (因为i,j之间的路径长度为只经过1-(k-1)号节点的最短路径)。 
![alt text](image.png)

~~~cpp
  for(int k=1;k<=n;k++)
  {
    
    for(int i=1;i<=k;i++)
    {
      for(int j=i+1;j<=n;j++)
      {
        ret=min((ll)f[i][j]+edge[i][k]+edge[k][j],ret);//保持类型一致
        
      }
    }
    for(int i=1;i<=n;i++)
    {
      for(int j=1;j<=n;j++)
      {
        f[i][j]=min(f[i][j],f[i][k]+f[k][j]);
        
      }
    }
  }
~~~
## 注意
- 分开存储f与edge
- 初始化
- 重边处理
- 包数据处理，0x3f3f3f3f,三个在一起爆int变成负数
  
## 错误
- 初始化别偷懒
~~~cpp
for(int i=1;i<=m;i++)//这是边数
  {
    f[i][i]=edge[i][i]=0;//爆re
    ll a,b,w;
    cin>>a>>b>>w;
    edge[a][b]=edge[b][a]=f[a][b]=f[b][a]=min(f[a][b],w);
    f[i][i]=0;
  }
~~~
- 你把数组开成了 long long，然后用 0x3f3f3f3f 去 memset 它：
~~~cpp
edge[110][110],f[110][110];
int INF=0x3f3f3f3f;
memset(f, INF, sizeof f);
~~~
诊断：memset 是按字节（byte）赋值的。当你传入 0x3f3f3f3f 时，它会截取最低位的一个字节 0x3f。
然后，它会把你 long long 的 8 个字节全部填满 0x3f。
于是，你的 long long 变量里的值变成了 0x3f3f3f3f3f3f3f3f（大约是 $4.5 \times 10^{18}$）。
在找最小环时，你执行了：f[i][j] + edge[i][k] + edge[k][j]。也就是三个 $4.5 \times 10^{18}$ 相加。
💥 核弹爆炸：三个加起来等于 $1.35 \times 10^{19}$，而 C++ 中有符号 64 位整数（long long）的极限大概是 $9.22 \times 10^{18}$。它爆 long long 溢出了！ 溢出后变成了一个极小的负数（大约是 -4702111234474983747）。
最后你的 min() 函数一看：“哇，这个负数比我的 ret 还要小！”于是把它存进去了。
