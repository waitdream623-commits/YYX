# 树状数组

## 性质
当树状数组的下标从 1 开始：可以得出如下性质：
1. 向上爬公式（找⽗亲）：结点编号为 x 时， x + lowbit(x) 等于⽗结点的编号。
2. 向前跳公式（找前⼀个相邻区间）：结点编号为 x 时， x − lowbit(x) 等于前⼀个相邻区间所在
的编号。
3. 维护的区间：结点编号为 x 时，维护的区间信息为 [x − lowbit(x) + 1, x
## 单点修改与区间查询
~~~ cpp
#define lowbit(x) (x & -x)//求最后一位1的大小
const int N = 1e5 + 10;
int t[N];
int n;
void modify(int x,int k)
{
    for(int i=x;i<=n;i+=lowbit(i))
    t[i]+=k;
}
int query(int x)//向前找，最终结果为[1,x]的值
{
    int sum=0;
    for(int i=x;i;i-=lowbit(i)){
        sum+=t[i];
    }
    return sum;
}
1. 创建时，默认整个数组全部为 ，每读⼊⼀个数 ，就相当于 位置的数增加了 。因此，调⽤单点修改函数就可以完成树状数组的创建。
2. 求区间[l,r]=query(r)-query(l-1);
~~~
