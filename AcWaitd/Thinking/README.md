# Thinking：思维训练

这里统一放贪心、构造、观察规律等题目，原 `Cnstructive_Algorithms` 的源码、笔记、图片和 CPH 测试已迁入。

练习顺序见：[贪心与构造思维题单（CF为主）](../../study/Problemset/贪心与构造思维题单（CF为主）.md)。

新题建议命名为 `CF_题号_字母_题名.cpp`，例如 `CF_1537_C_Challenging_Cliffs.cpp`。先在本目录创建源码，再导入 CPH 测试。

已经存在于 `Contest`、`CF` 或其他专题目录的题不重复复制，用笔记链接即可。每次做完只记录核心观察、正确性理由和踩坑点，完成状态仍在题单中维护。
