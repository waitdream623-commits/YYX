# 题解

## 分析
- 10^10数据量，无法全部判断素数
- 但判断范围在10^6,可以将其单独判断。
- 已知埃氏筛与欧拉筛，前置是小的素数，进而筛掉倍数
---
## 解决
- 最大的数为R，素数一个小于$\sqrt{R}$，一个大于$\sqrt{R}$
因此我们只需要筛出1 ~ $\sqrt{R}$中素数，进而可以完全判断L ~ R区间内素数；
- 区间映射st[i-l];因为无法开辟那么大数组

## 错误回放
- 处理l~r区间数，倍数筛掉时没开ll，可能导致j超int,当j位于int边界，此时加上p[j],会超
~~~cpp
 for(ll j=(l+p[i]-1)/p[i]*p[i];j<=r;j+=p[i])//此处开ll，可能超int
    //因此里面l+p[i]也可能超int
    {
        if(j==p[i])continue;//一倍；
        st2[j-l+1]=true;
    }
~~~
