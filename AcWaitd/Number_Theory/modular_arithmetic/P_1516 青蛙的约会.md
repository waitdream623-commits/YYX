## 错误回放
- 求任意二元一次实际解转换，t/d不一定为整数，但c/d一定整除(有解情况下)
  ~~~cpp
  ll t, t1;
  ll d = exgcd(a, b, t, t1); // 判断是否有解
  
  if (c % d == 0)
  {
    ll dx = b / d;
    // 关键修复：先除以 d，并且步步取模防止溢出
    t = (t % dx) * ((c / d) % dx) % dx; 
    
    // 转化为最小正整数解
    cout << (t % dx + dx) % dx;
  }
  else
  {
    cout << "Impossible";
  }
  ~~~
