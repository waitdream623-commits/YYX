# 线段树
## 使用场景
1. 有 n(n ≤ 10^5 ) 个数， q(1 ≤ 10^5 ) 次操作，`每次操作为询问区间 [l, r] 的和。
2. 有 n(n ≤ 10^5 ) 个数， q(1 ≤ 10^5 ) 次操作，操作有两种：
a. 查询区间 [l, r] 的和；
b. 将第 i 个数修改成 x 。
1. 有 n(n ≤ 10^5 ) 个数， q(1 ≤ 10^5 ) 次操作，操作有两种：
a. 查询区间 [l, r] 的和；
b. 将区间 [l, r] 的数全部修改成 x 。
1. 有 n(n ≤ 10^5 ) 个数， q(1 ≤ 10^5 ) 次操作，每次操作为区间 [l, r] 的最⼤值或者最⼩值。

这个其实是 **RMQ**（Range Minimum/Maximum Query） 问题。
以上问题，采⽤暴⼒解法显然会超时。
接下来，我们学习⼀种树形数据结构 
- 线段树：
• 线段树是⼀棵⼆叉树，常⽤来维护区间信息；
• 可以在**log**级别的时间复杂度内完成：区间的单点修改，区间修改、区间查询（区间和，区间最⼤最⼩值）等操作。
