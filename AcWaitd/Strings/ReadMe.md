## 五、完成标准（和字典树同一条）

```
写完模板  →  ① 编译通过  →  ② 对拍通过  →  才算完成
```

KMP 的对拍**特别好写**，比字典树简单：

| 设置 | 值 | 为什么 |
| --- | --- | --- |
| 主串长度 | ≤ 20 | 暴力逐位置比对就够 |
| 模式串长度 | ≤ 5 | 保证"能匹配上"和"匹配失败"都高频出现 |
| 字母表 | **只放 `a` / `b`** | 让**重叠匹配**和**重复前缀**高密度出现 |

> 随机主串 → 用暴力 `find` / 手写双重循环算所有出现位置 → 和 KMP 比对。
> 参考已有样板：`Trie/trie_stress.cpp`（结构完全一样，换掉操作集合即可）。

**必须覆盖的边界**：模式串比主串长、模式串 == 主串、只有 1 个字符、主串末尾刚好匹配上（防"循环终止条件写错"）。
