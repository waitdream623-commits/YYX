## 解决问题
1. 引⼊
【RMQ 问题】
• 对于⼀个⻓度为 n 的序列，有 m 次查询操作，每次查询为⼀个区间 [l, r] 的最⼤值。
2. 
【ST 表】
ST 表（Sparse Table，稀疏表）是基于动态规划和倍增实现的数据结构，形式上是⼀张⼆维表格。ST表通过预处理维护⼀些区间信息，从⽽快速处理区间查询。（有点像前缀和数组~）由于在查询前需要预处理，ST 表基本上只能解决静态问题。
【ST 表维护的信息】
ST 表维护的信息需要满⾜结合律以及可重复贡献，例如区间最值以及区间最⼤公约数。如果不满⾜结合律以及可重复贡献，ST 表就不能解决，例如区间和以及区间乘积。

~~~ cpp
void wait()
{
    int n,m;cin>>n>>m;//读入数据个数n，询问次数m;
    vector<vector<int>>f(n+1,vector<int>(25));
    lg[0]=-1;//后续lg[1]=0;
    for(int i=1;i<=n;i++){
        
        cin>>f[i][0];
        lg[i]=lg[i>>1]+1;//预处理log实现查询O(1);
    
    }
    //预处理
    for(int j=1;j<=log2(n);j++)//最长n
    {
        for(int i=1;i+(1<<j)-1<=n;i++)//i结束位置为最后一个点，长度为(1<<j)，此时包含完所有数据;
        {
            f[i][j]=max(f[i][j-1],f[i+(1<<(j-1))][j-1]);//分成两部分
        }
    }
    while(m--)
    {
        int l,r;cin>>l>>r;
        //找到适合区间长度
        int len=r-l+1;
        //int k=log2(len);//优化预处理
        int k=lg[len];
        int ret=max(f[l][k],f[r-(1<<k)+1][k]);
        cout<<ret<<"\n";//不用endl，大幅度降低时间
    }
}
~~~
**解释**

- 对于预处理O(nlogn),查询O(1);
- **预处理**
  - f[i][j]表示起点为i，长度为2^j^;
  - i+len表示下一个区间起点
  - i-len表示上一个区间终点
- **查询**
  - lg数组，大小为数据长度，预处理log2，在读入时候初始化，lg[0]=-1,让lg[1]=0;
  - 结果为区间[l,l+2^k^-1],[r-2^k^+1,r]结合
