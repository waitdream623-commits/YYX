【RMQ 问题】
• 对于⼀个⻓度为 n 的序列，有 m 次查询操作，每次查询为⼀个区间 [l, r] 的最值（RMQ = Range Maximum/Minimum Query，最大/最小都算）。
2. 
【ST 表】
ST 表（Sparse Table，稀疏表）是基于动态规划和倍增实现的数据结构，形式上是⼀张⼆维表格。ST表通过预处理维护⼀些区间信息，从⽽快速处理区间查询。（有点像前缀和数组~）由于在查询前需要预处理，ST 表基本上只能解决静态问题。它和快速幂、LCA 的 up 表同属“倍增家族”。
【ST 表维护的信息】
ST 表维护的信息需要同时满足两个条件：
- 结合律：两块信息能合并
- 可重复贡献（幂等，op(x, x) = x）：两块可以重叠，重复计算同一元素不影响答案
例如区间最值、区间最大公约数都满足；区间和、区间乘积只满足结合律、不满足可重复贡献（重叠部分会被算两次），所以不能用 ST 表。
一句记住：前缀和靠“可减”消掉重叠，ST 表靠“可重复贡献”无视重叠。

~~~ cpp
void wait()
{
    int n,m;cin>>n>>m;//读入数据个数n，询问次数m;
    vector<vector<int>>f(n+1,vector<int>(25));//竞赛更常用静态数组 int f[N][logN]，列数按数据范围取 lg[n]+1，缓存更友好
    lg[0]=-1;//全局 int lg[N]（按数据范围开）；这样 lg[1] 就 = 0
    for(int i=1;i<=n;i++){
        
        cin>>f[i][0];
        lg[i]=lg[i>>1]+1;//预处理log实现查询O(1);
    
    }
    //预处理
    for(int j=1;j<=lg[n];j++)//最长 n；j 上界 = floor(log2(n))，用 lg 表避开浮点 log2
    {
        for(int i=1;i+(1<<j)-1<=n;i++)//i 为起点，块长 2^j，块尾 i+2^j-1 不能超过 n
        {
            f[i][j]=max(f[i][j-1],f[i+(1<<(j-1))][j-1]);//分成两部分
        }
    }
    while(m--)
    {
        int l,r;cin>>l>>r;
        //找到适合区间长度
        int len=r-l+1;
        //int k = log2(len);//浮点写法，不推荐，直接用 lg 表
        int k=lg[len];
        int ret=max(f[l][k],f[r-(1<<k)+1][k]);
        cout<<ret<<"\n";//不用endl，大幅度降低时间
    }
}
~~~
**解释**

- 复杂度：预处理 O(nlogn)，单次查询 O(1)（两次查表 + 一次比较），空间 O(nlogn)
- **预处理**
  - f[i][j] 表示起点为 i、长度为 2^j 的区间 [i, i+2^j-1] 的信息
  - 合并左右两半：左半 [i, i+2^(j-1)-1]，右半 [i+2^(j-1), i+2^j-1]（右半起点 = i + 2^(j-1)，不是 i-len）
  - 两半都在 j-1 层算好了，所以 j 从 1 枚举到 lg[n]
- **查询**
  - lg 数组：lg[i] = floor(log2(i))，读入时递推 lg[i] = lg[i>>1] + 1，令 lg[0] = -1 则 lg[1] = 0
  - 取 k = lg[len]，答案 = max(f[l][k], f[r-(1<<k)+1][k])，即两块 [l, l+2^k-1] 与 [r-2^k+1, r] 合并
  - 为什么两块一定覆盖 [l,r]：
    - 2^k ≤ len → 两块都落在 [l,r] 内
    - len < 2^(k+1) → 2·2^k > len → 两块重叠或相接，中间没有缝
  - 重叠部分被重复计算也没关系——这正是“可重复贡献”允许的

### GCD求法
~~~ cpp
int gcd(int a, int b)
{
    return b?gcd(b,a%b):a;
}
~~~



### 选型对比

| 结构 | 修改 | 查询 | 信息要求 |
|------|------|------|---------|
| 前缀和 | ✗ | O(1) | 可减 |
| ST 表 | ✗ | O(1) | 可重复贡献 |
| 树状数组 | O(logn) | O(logn) | 可减 |
| 线段树 | O(logn) | O(logn) | 结合律即可 |

### 自测
小数据随机对拍（暴力 O(len) 扫区间），重点测三种边界：l == r、len 恰为 2 的幂、查询跨全区间。

### 例题
- P1198 最大数（只在末尾插入 + 查询末尾 L 个数的最大值），线段树可做，也能用“倒着建 ST 表”：
  - 因为查询永远问末尾，只需维护“以右端点结尾”的表：g[i][j] = max(g[i][j-1], g[i-2^(j-1)][j-1])
  - 插入到位置 i 时只更新 j = 1..lg[i]，左邻块都已算好 → 单次插入 O(logn)
  - 查询 [i-L+1, i]：k = lg[L]，答案 = max(g[i][k], g[i-L+2^k][k])
  - 错误点：答案会超 int，记得开 long long
