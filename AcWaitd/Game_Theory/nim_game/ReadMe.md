# Nim 博弈

## 核心模型

$n$ 堆石子，每堆有 $a_i$ 个，两人轮流从任意一堆取任意正数个，取走最后一个者胜。

**结论**：
$$
\text{先手必败} \iff a_1 \oplus a_2 \oplus \cdots \oplus a_n = 0
$$

其中 $\oplus$ 表示按位异或。

## 理解
- 异或和为 $0$ 的状态是**必败态**（P态），任何操作都会使异或和变为非 $0$
- 异或和非 $0$ 的状态是**必胜态**（N态），总有一种取法使异或和变回 $0$
- 构造取法：找到异或和的最高位，从对应堆中取走 $a_i - (a_i \oplus sum)$ 个

## 变体
- **反 Nim**（取最后一个输）：特殊处理全为 $1$ 的情况
- **阶梯 Nim**（Staircase Nim）：只考虑奇数台阶上的石子
- **Moore's Nim**：每次最多从 $k$ 堆中取
