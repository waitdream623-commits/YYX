# Bash 博弈（巴什博弈）

## 核心模型

一堆石子 $n$ 个，两人轮流取，每次至少取 $1$ 个、最多取 $m$ 个，取走最后一个者胜。

**结论**：
$$
\text{先手必败} \iff n \bmod (m+1) = 0
$$

## 理解
- 如果能给对方留下 $(m+1)$ 的倍数，无论对方取 $k$ 个（$1 \le k \le m$），你总能取 $(m+1-k)$ 个维持倍数
- 最终对方面对 $m+1$ 时，取任何数量都会剩下 $1 \sim m$ 个，你一次性取完
- SG函数找规律

## 变体
- 取 $[L, R]$ 区间：判定条件变为 $n \bmod (L+R)$
- 取最后一个**输**（反 Nim）：特殊处理 $n \le m$ 的情况
