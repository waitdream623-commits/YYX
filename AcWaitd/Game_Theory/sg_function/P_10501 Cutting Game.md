# 题解

## 分析
- 游戏由多张独立的纸组成，每次只能操作其中一张，且操作后将其分裂为独立的两个子状态。这完美符合 Multi-Nim（独立组合游戏） 的特征。
- 只要能算出每种大小的纸张 $(W, H)$ 对应的 SG 值，多个纸张并存的状态只需要将它们各自的 SG 值进行异或（XOR）即可。**这是子游戏需要异或**
- 反常游戏，当切出1*1为胜利状态
  - 任何包含边长为 1 的状态，都是当前玩家的“必胜点”。

  - 换句话说，谁要是把一张纸切成了包含边长为 1 的两部分，谁就等同于双手把胜利奉送给了对手！
  - 所以应该寻找必败态，标记sg为0；满足sg函数
- 当一个游戏可以拆解为多个彼此完全独立、互不影响的子游戏时（Multi-Nim 模型），如果两位玩家轮流在其中任意一个子游戏中进行合法操作，那么总局面的博弈状态（SG 函数值）就等于所有子游戏 SG 值的异或和。
- 切开纸片相当于分成两堆，把一个大游戏拆成两个，两个变成四个，每次都是求^,最终返回的是大游戏的sg值
