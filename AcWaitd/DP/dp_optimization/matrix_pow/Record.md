## 2026-09-23：LeetCode 70 爬楼梯（入门）

### 思路演进（暴力 → 优化）

| 做法 | 复杂度 | 说明 |
|------|--------|------|
| 递归 | $O(2^n)$ | 大量重复子问题，别写 |
| 线性 DP | $O(n)$ | `f[i] = f[i-1] + f[i-2]`，$n \le 45$ 够用 |
| 矩阵快速幂 | $O(\log n \cdot 2^3)$ | $n$ 到 $10^{18}$ 唯一解 |

**关键认识**：$n \le 45$ 时矩阵快速幂**反而更慢**（常数大）——优化的意义在于 $n$ 极大，不在"看起来高级"。

### 矩阵怎么来的

$$f_n = f_{n-1} + f_{n-2}$$

状态是「连续两项」，写成列向量：

$$\begin{bmatrix} f_n \\ f_{n-1} \end{bmatrix} = \begin{bmatrix} 1 & 1 \\ 1 & 0 \end{bmatrix}\begin{bmatrix} f_{n-1} \\ f_{n-2} \end{bmatrix}$$

即 $S_n = A\,S_{n-1}$，展开得 $S_n = A^{\,n-2} S_2$，其中 $S_2 = [f_2, f_1]^\top = [2, 1]^\top$。

答案 = $A^{n-2}$ 的第 0 行点乘 $S_2$ → `res[0][0]*f[2] + res[0][1]*f[1]`（当天手写的版本就是这一步）。

**构造口诀（要形成肌肉记忆）**：
- 第 0 行 = 递推系数照抄（$c_1, c_2, \dots, c_k$）
- 第 1 行起 = 上一行右移一格（$A_{i,i-1} = 1$，负责把老状态"搬运"下来）

### 当天代码的两处细节

```cpp
// 1. 快速幂起点必须是单位矩阵（当天写对了）
Matrix c(n, vector<long long>(n, 0));
for (int i = 0; i < n; i++) c[i][i] = 1;

// 2. 边界：n <= 2 要特判，否则 n-2 是负数 → 快速幂里 b >>= 1 对负数实现定义
if (n <= 2) return n;
```

### 坑（当天代码没踩，但要记死）

| 坑 | 说明 |
|----|------|
| 系数与 $n$ 有关 | $c(n)$ 变系数 → 矩阵不固定，矩阵快速幂**直接失效** |
| 转移含 `min/max` | 不满足矩阵分配律（除非 min-plus 广义矩阵） |
| 矩阵乘法顺序 | $A B \ne B A$，`res = res * a` 不能反 |
| 行向量 / 列向量 | 本模板用**列向量** $S_n = A S_{n-1}$；若改用行向量 $V_n = V_{n-1}A$，矩阵要转置 |
| 指数取 $n-k$ | 取 $n$ 会整体偏移一个 $A$；取 $n-1$ 也要对应改初值 |
| 溢出 | 两个 $<10^9$ 数相乘 ≈ $10^{18}$，`long long` 刚好安全；模数 $\ge 10^{10}$ 必须 `__int128` |

### 检验方法（当天用的）

- 小 $n$ 跑**暴力 DP** 对拍：$n \le 300$ 全对才算过
- 大 $n$（$10^{18}$）只看**能否瞬间返回**，值无法手算验证

> **一句话核心**：矩阵快速幂不是"新算法"，是**把"递推 $n$ 次"换成"矩阵幂 $\log n$ 次"**——

$$\underbrace{A \cdot A \cdots A}_{n \text{ 次}} \quad \longrightarrow \quad A^{n} \text{（二进制拆分，} O(\log n) \text{ 次乘法）}$$
