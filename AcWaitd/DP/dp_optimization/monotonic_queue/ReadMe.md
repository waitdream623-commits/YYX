## 判断三步

1. 写出转移方程：$dp_i = \min/\max_{j}\big(dp_j + cost(i)\big)$
2. **把 $cost(i)$ 提出括号** → 括号里只剩 $dp_j$，与 $i$ 无关
3. 检查 $j$ 的合法区间左右端点**随 $i$ 单调不减** → 用单调队列维护窗口内 $dp_j$ 的最值

三步全过 → 可以做；第 2 步提不出来（出现 $a_j \cdot b_i$）→ 去 `slope_optimization/`。

## 本质

> 单调队列优化的 DP，**比朴素 DP 只多一件事**：在「填表」前先把过期决策弹掉、把劣质决策弹掉。
> 所以它 ≈ 滑动窗口最值 + DP。**先会滑动窗口，再回来看这个。**

## 踩坑预告

- 队列存**下标**而不是值（要判过期）
- 求 min 用递增队列，求 max 用递减队列 —— **别写反，也别靠背，画两个数自己推**
- 先弹过期，再弹劣质，最后入队取答案 —— **顺序错了答案会偏**
