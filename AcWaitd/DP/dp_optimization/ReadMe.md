## 优化到底在优化什么

$$T = \underbrace{\text{状态数}}_{\text{状态设计决定}} \times \underbrace{\text{每个状态的转移枚举量}}_{\text{DP 优化决定}}$$

状态数一般压不动（要压那是**状态设计**的活儿）。所以：

> **DP 优化 = 把「每个状态的转移枚举量」从 $O(k)$ / $O(n)$ 降到 $O(1)$ 或 $O(\log n)$。**

TLE 时先手算 $状态数 \times 转移枚举量$，才能判断是**改状态**还是**加优化**——这是选择问题，不是记忆问题。

## 三大优化的触发条件（先判类型，再想代码）

| 优化 | 转移方程长什么样 | 复杂度 | 目录 |
|------|------------------|--------|------|
| **单调队列** | $dp_i = \min/\max_{j \in [i-m,\ i-L]} \big(dp_j\big) + cost(i)$，**j 的合法区间随 i 单调滑动**，且 $cost(i)$ 与 $j$ 无关 | $O(nk) \to O(n)$ | `monotonic_queue/` |
| **斜率优化** | $dp_i = \min/\max_{j < i}\big(dp_j + f(j)\cdot g(i) + \dots\big)$，**j 与 i 乘在一起、无法分离** | $O(n^2) \to O(n)$ / $O(n\log n)$ | `slope_optimization/` |
| **矩阵快速幂** | **线性固定递推**：$f_n = \sum_{t=1}^{k} c_t f_{n-t}$，系数 $c_t$ 与 $n$ 无关 | $O(nk) \to O(\log n \cdot k^3)$ | `matrix_pow/` |

### 一句话区分（重点）

| 现象 | 结论 |
|------|------|
| cost 里 **i 和 j 能分离**，且 j 的窗口单调滑动 | 单调队列 |
| cost 里 **i 和 j 相乘**（出现 $a_j \cdot b_i$） | 斜率优化 |
| 转移是**线性的**、阶数 $k$ 固定、$n$ 巨大（$10^{18}$ 级） | 矩阵快速幂 |
| 出现 `min/max`、乘法项、$c(n)$ 变系数 | **三条都别用**，回去改状态设计 |

### 反例警告（别硬上优化）

- $n \le 10^6$ 且 $k \le 3$：矩阵快速幂 $O(\log n \cdot k^3)$ 的常数比直接 $O(nk)$ 还慢 → **直接递推**
- 转移里带 `min/max`：矩阵乘法不成立（除非用 min-plus 广义矩阵，那是另一套东西）
- 系数含 $n$（如 $f_n = n f_{n-1}$）：矩阵不固定，只能用**矩阵加速分治/多项式**那类技巧

## 必背检查表（写之前先答）

1. 转移方程写出来了吗？$dp_i$ 只依赖 j 的**哪一段**？
2. $i$ 和 $j$ 在 cost 里是**相加**、**相乘**、还是**分离**？
3. $n$ 的量级是多少？$10^{18}$ 还是 $10^6$？（决定要不要上矩阵）
4. 优化后复杂度算对了吗？**中间乘法会不会溢出**？
