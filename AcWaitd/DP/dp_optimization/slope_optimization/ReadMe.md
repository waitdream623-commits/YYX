## 判断

1. 转移：$dp_i = \min\limits_{j<i}\big(dp_j + f(j, i)\big)$
2. $f(j, i)$ 展开后**含 $a_j \cdot b_i$ 这种乘积项**，$i$ 与 $j$ **无法分离**
3. 把式子整理成 $y = k x + b$：**j 相关的量当 $(x, y)$，i 相关的量当 $k, b$**
   - 决策点：$\big(x_j = \text{只含 } j,\ y_j = \text{只含 } j\big)$
   - 查询：用斜率 $k_i$ 去切凸包（求 min → 下凸壳；求 max → 上凸壳）
4. 决策单调性
   - $k_i$ **单调** → 单调队列维护凸包，$O(n)$
   - $k_i$ 不单调 → 二分凸包 / 李超树 / CDQ 分治

## 为什么比单调队列难

> 单调队列是"**删点**"（劣质决策直接扔）；斜率优化是"**切凸包**"（几何视角）。
> 核心难点不在代码，而在**第 3 步的式子变形**——这一步做不出来，后面全是空谈。

## 触发信号

- 转移里出现 $dp_j + a_j \cdot i$、$(s_i - s_j)^2$、$(i - j)^2$ 这类**平方/乘积**结构
- 数据范围 $n \le 10^5$ 而朴素转移是 $O(n^2)$ → 卡在优化上
