# 区间 DP

## 核心模式

**三板斧**：`len` → `l` → `k`

```cpp
for (int len = 2; len <= n; len++)           // 1. 区间长度
    for (int l = 1; l + len - 1 <= n; l++) { // 2. 左端点
        int r = l + len - 1;
        for (int k = l; k < r; k++)           // 3. 分割点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost(l, r));
    }
```

## 状态定义

$dp[l][r]$ = 区间 $[l, r]$ 上的最优解

## 环形问题处理

复制一倍数组：
```cpp
for (int i = 1; i <= n; i++) a[i + n] = a[i];
// 答案取 len=n 的区间：max(dp[i][i+n-1]) for i=1..n
```

## 两端扩展型

$dp[l][r][0/1]$ 表示区间 $[l,r]$，当前在左端（0）还是右端（1）：
```cpp
dp[l][r][0] = min(dp[l+1][r][0] + cost_l, dp[l+1][r][1] + cost_r);
dp[l][r][1] = min(dp[l][r-1][0] + cost_l, dp[l][r-1][1] + cost_r);
```

## 括号匹配的最少插入次数

`dfs(l, r)` 表示把 `s[l..r]` 补成合法串最少要插入几个括号。空区间返回 `0`，单个括号返回 `1`。首尾能配成 `()` 或 `[]` 时，可取 `dfs(l+1, r-1)`。同时枚举每个切点 `k = l..r-1`，取 `dfs(l, k) + dfs(k+1, r)` 的最小值。切点从 `l` 开始，才能把单独的左端拿出来补一个括号。比如 `)[]` 可以拆成 `)` 和 `[]`，答案是 `1`。

求最小值时用区间长度 `r-l+1` 作初值，每个原字符各补一个括号就能达到这个上界。加记忆化后有 `O(n²)` 个区间，每个区间枚举 `O(n)` 个切点，总时间 `O(n³)`，空间 `O(n²)`。
