- 2与4列单独判断，对1，3，5进行分析
- 奇数列相互独立，仅需要考虑一个
- 状态定义
  - f[i][{0,1}][{0,1}]表示前i个，第一个是否是元音，第i个是否是元音的方案数，1为元音
- 状态转移
  - f[i][j][0]=(f[i-1][j][0]+f[i-1][j][1])*21
  -  f[i][j][1]=f[i-1][j][0]*5;
- 再枚举偶数列情况2^4
  ~~~cpp
  F(a, 0, 1) F(b, 0, 1) F(c, 0, 1) F(d, 0, 1){//枚举四个点
		int w1 = 0, w2 = 0, w3 = 0;
		F(x, 0, 1) F(y, 0, 1) {//枚举第一个与最后一个
			int cal = dp[n][x][y];
			bool f1 = (!x || !a) && (!y || !b);//不能连续为元音
			bool f2 = (!x || !c) && (!y || !d);
			if (f1) (w1 += cal) %= mod;
			if (f1 && f2) (w2 += cal) %= mod;//第3列
			if (f2) (w3 += cal) %= mod;
		}
		(res += w1 * w2 % mod * w3 % mod * w[a] % mod * w[b] % mod * w[c] % mod * w[d] % mod) %= mod;
	}
  ~~~
