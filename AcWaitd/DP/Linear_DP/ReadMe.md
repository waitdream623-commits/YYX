### P1115 最大子段和

- **状态**：`f[i]` = 以 `a[i]` 结尾的最大子段和
- **转移**：`f[i] = max(a[i], f[i-1] + a[i])` —— 自己单干 / 接上之前
- **坑**：
  - 循环边界 `i<=n` 不是 `i<=1`
  - `ret` 初始化为 `-INF` 或 `a[1]`，不能是 `0`（全负情况输出 0）

### B3637 最长上升子序列（LIS）

#### O(n²) 做法
- **状态**：`f[i]` = 以 `a[i]` 结尾的 LIS 长度
- **转移**：`f[i] = max(f[j] + 1)` 其中 `j < i` 且 `a[i] > a[j]`
- **坑**：
  - 初始化所有 `f[i] = 1`，不能只初始化 `f[1]`
  - 答案是 `max(f[1..n])`，不是 `f[n]`——LIS 不一定以最后一个元素结尾

#### O(n log n) 贪心 + 二分
- 维护 `f[len]` = 长度为 len 的上升子序列的**末尾元素最小值**
- `f` 天然单调递增
- 遍历 `a[i]`：
  - `a[i] > f[len]` → `f[++len] = a[i]`（接上）
  - 否则 → `lower_bound(f+1, f+1+len, a[i])` 找到第一个 ≥ a[i] 的位置替换，使末尾尽可能小
- **非严格上升**：append 条件改为 `a[i] >= f[len]`，replace 用 `upper_bound`，upper让相等时尽可能更新更小，后续更容易接长

### 通百道

最大子段和的框架改一下就是：

- **LIS O(n²)**：`dp[i] = max(dp[j] + 1)` 当 `a[j] < a[i]`，初始化 `dp[i]=1`
- **LIS O(n log n)**：`f[len]` 维护末尾最小值，`lower_bound` 替换
- **最大子矩阵**：把行压缩成一维，每列求和，然后跑最大子段和
- **最长连续递增子序列**：`dp[i] = dp[i-1] + 1` 当 `a[i] > a[i-1]`

**核心**：线性 DP 的状态往往定义成 **"以 i 结尾的 XXX"**，转移来源唯一——`i-1`。
