## DP 三大核心要素

### 1. 状态定义
- 问什么定义什么：`dp[i][j]` = 前 i 个物品，容量 j 时的最大价值
- 必要时加维度：`dp[l][r][0/1]` 表示区间 + 位置状态

### 2. 状态转移
- 从哪里来（填表法）：`dp[i] = max(dp[i-1], dp[i-w] + v)`
- 往哪里去（刷表法）：`dp[i+w] = max(dp[i+w], dp[i] + v)`

### 3. 初始化（最容易错！）

| 场景 | 初始化 | 原理 |
|------|--------|------|
| 求 max 价值（最多装满） | 全部 0 | 装 0 体积也是合法状态 |
| 求 max 价值（恰好装满） | f[0]=0，其余 -INF | 非零容量不可达 |
| 求 min 价值（恰好装满） | f[0]=0，其余 INF | 未到达状态不可用 |
| 计数/方案数 | dp[0]=1，其余 0 | 空集算一种方案 |

## 各背包变种速查

| 类型 | 核心循环 | 关键 |
|------|----------|------|
| 01 背包 | `for(j=W; j>=w[i]; j--)` | **倒序**，每件最多 1 次 |
| 完全背包 | `for(j=w[i]; j<=W; j++)` | **正序**，每件无限次 |
| 多重背包 | 二进制拆分 → 01 背包 | `while(k<=cnt)` + 剩余 |
| 分组背包 | `for(组) for(j=W; j>=0; j--) for(组内)` | 组→容量→物品，每组最多选 1 |
| 二维费用 | `for(j=M; j>=a[i]; j--) for(k=D; k>=b[i]; k--)` | 两层倒序 |
| 计数背包 | `dp[j] = (dp[j] + dp[j-w[i]]) % MOD` | dp[0]=1 |

## 线性 DP 核心模板

```cpp
// 最大子段和
dp[i] = max(dp[i-1] + a[i], a[i]);

// LIS O(n²)
for(int i=1; i<=n; i++)
    for(int j=1; j<i; j++)
        if(a[j] < a[i]) dp[i] = max(dp[i], dp[j]+1);

// LIS O(n log n)
vector<int> d;
for(int x : a) {
    auto it = lower_bound(d.begin(), d.end(), x);  // 严格上升
    if(it == d.end()) d.push_back(x);
    else *it = x;
}

// 编辑距离
dp[i][j] = min({dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+(a[i]!=b[j])});
```

## 区间 DP 核心模板

```cpp
// 三板斧：len → l → k
for(int len=2; len<=n; len++)           // 区间长度
    for(int l=1; l+len-1<=n; l++) {     // 左端点
        int r = l + len - 1;
        for(int k=l; k<r; k++)           // 分割点
            dp[l][r] = min(dp[l][r], dp[l][k] + dp[k+1][r] + cost(l,r));
    }

// 环形问题：复制一倍数组
for(int i=1; i<=n; i++) a[i+n] = a[i];
// 最后取 max(dp[i][i+n-1]) for i=1..n

// 两端扩展型（关路灯）
dp[l][r][0] = min(dp[l+1][r][0]+cost, dp[l+1][r][1]+cost);  // 在左端
dp[l][r][1] = min(dp[l][r-1][0]+cost, dp[l][r-1][1]+cost);  // 在右端
```

## 避坑清单

| ❌ 常见错误 | ✅ 正确做法 |
|------------|------------|
| 01背包正序枚举 j | 倒序！`for(j=W; j>=w[i]; j--)` |
| dp 数组忘记初始化 | 求 max→0, 求 min→INF, 计数→dp[0]=1 |
| 区间 DP 枚举顺序写反 | len 外循环，l 中循环，k 内循环 |
| 环形问题不会处理 | 复制一倍数组，最后取 max(dp[i][i+n-1]) |
| LIS 用错 lower/upper_bound | 严格上升→lower_bound，不下降→upper_bound |
| 多重背包忘记剩余部分 | 二进制拆分后 `if(cnt>0)` 再加一个 |
| 读题漏看"取模" | 蓝桥杯很多题要取模，中间也取模 |
