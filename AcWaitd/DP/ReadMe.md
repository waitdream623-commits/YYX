# DP 复建 + 蓝桥杯 CA 组国赛冲刺计划（5.26 → 6.6 共 11 天）

## 当前问题诊断

三月学了线性DP/背包/区间DP，但现在"一头蒙"的原因：
- 只是看了/懂了，**代码写得太少**，没有形成肌肉记忆
- DP 的关键不是"看懂状态转移"，而是**闭卷能写出正确代码**
- 蓝桥杯考的不是创新思维，是**模板熟练度 + 实现速度**

## 核心原则

1. **每天至少手写 3 道 DP 题**，不看模板闭卷写
2. **每道题写完后对照模板找差距**，发现一次 bug 记一次 notes
3. **先恢复手感，再练蓝桥真题**
4. DP 题重点练**初始化**和**边界条件**（这是最容易错的地方）

## 蓝桥杯 CA 组应试策略

### 填空题（2-3 题）
- 不要手算！写代码暴力/打表
- DFS 全排列、组合枚举是填空题利器
- 注意数据范围，能用暴力绝不想数学公式

### 编程题（5-7 题）
- 先扫一遍所有题，从简单的开始拿分
- DP 题：先写暴力递推验证思路，再优化
- 图论题：你已有最短路/并查集基础，放心做
- 数论题：你的强项，优先拿分
- 不会的题写部分分（暴力、特殊数据），绝不空着

### 你的优势项（优先抢分）

## 避坑清单（针对 DP）

| ❌ 常见错误 | ✅ 正确做法 |
|------------|------------|
| 01背包正序枚举 j | 倒序！`for(j=W; j>=w[i]; j--)` |
| dp 数组忘记初始化 | 求 max→0, 求 min→INF, 计数→dp[0]=1 |
| 区间 DP 枚举顺序写反 | len 外循环，l 中循环，k 内循环 |
| 环形问题不会处理 | 复制一倍数组，最后取 max(dp[i][i+n-1]) |
| LIS 用 upper_bound 还是 lower_bound | 严格上升→lower_bound，不下降→upper_bound |
| 多重背包忘记剩余部分 | 二进制拆分后 if(cnt>0) 再加一个 |
| 二维 dp 用 vector<vector<int>> 超时 | 用数组/一维滚动优化 |
| 读题漏看"取模" | 蓝桥杯很多题要取模，注意中间也取模 |

## 模板速查（必须闭卷写出来的 5 个代码）

1. **01 背包（滚动数组）** — 4 行
2. **完全背包（滚动数组）** — 与上者只差正序/倒序
3. **LIS O(n log n)** — `lower_bound` 版本
4. **石子合并（区间DP）** — len→l→k 三板斧
5. **DFS 全排列** — `vis` 数组 + 回溯
