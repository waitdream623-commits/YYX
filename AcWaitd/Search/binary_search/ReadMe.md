# 二分专题

> 配套课程：讲解 **006 二分搜索**、讲解 **051 二分答案法与相关题目**
> 模板：`Binary_Search_Template.cpp`（找位置）、`Binary_Answer_Template.cpp`（二分答案）

## 一、两种二分，先分清

| 类型 | 问题长什么样 | 关键 |
|---|---|---|
| **二分查找** | 有序数组里找"第一个 ≥ x / 最后一个 ≤ x / 出现次数" | 写对 `lo/hi` 的闭开与 `mid` 取整 |
| **二分答案** | 求"最大化的最小值 / 最小化的最大值"，判定容易、最优难求 | 写对 `check` 的单调性 |

**识别信号**：题目出现"最大值最小 / 最小值最大 / 至少 / 至多 + 求一个最优边界"→ 二分答案。

## 三、易错点清单（每题踩过的写这里）

1. **`mid` 上取整**：找"最后一个满足"必须 `(lo + hi + 1) >> 1`，否则 `lo == hi-1` 时死循环
2. **`check` 方向搞反**：先手推 `x` 变大时可行性怎么变，再选模板 A/B
3. **值域开小**：答案可能到 `1e18`（用 `ll`），实数题别用 `< 1e-6` 判停
4. **`check` 里溢出**：累加 `sum` 到 `>= m` 就 `return true`
5. **二分 + 差分/前缀和**：`check` 内每次重算差分数组，别忘了清空
6. **边界**：答案能不能取到 `0` / 上界 `R` 本身？用 `n+1`、`0` 当哨兵省特判
