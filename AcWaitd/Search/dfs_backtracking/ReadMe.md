## DFS 回溯核心框架

```
void dfs(...) {
    if (到达边界) { 处理结果; return; }
    for (所有选择) {
        if (可以选) {
            标记;        // vis[i] = 1 或 st[i]++
            选择;        // path.push_back(i) 或 sum += a[i]
            dfs(下一层);
            撤销选择;    // path.pop_back()
            撤销标记;    // vis[i] = 0 或 st[i]--
        }
    }
}
```

**四步缺一不可，忘回溯 = 死循环。**

## 避坑清单

| ❌ 错误 | ✅ 正确 |
|---------|---------|
| `dfs(start+1)` 组合中 | `dfs(i+1)` — 下一层起点由当前选的数决定 |
| 全局变量手动 `sum+=` / `sum-=` | 参数传值 `dfs(i+1, sum + a[i])` — 自动回溯 |
| 对角线用 `abs(r-c)` | `r-c+n` — 加偏移量映射到非负，不合并不同对角线 |
| `cal` 找最大重叠 | **最小重叠**使龙最长；从 k=1 往上找 |
